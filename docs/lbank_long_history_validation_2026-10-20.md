# LBank 알람 대체 전략의 장기 검증 — 2026-10-20 KST

**판정: 운영 교체에 채택할 후보 0개. 전략의 우위와 알람 성능의 획기적 개선은 확인하지 못했다.**

장기 원본 자료, 재현 코드, 후보별 거래 기록은 확보했다. 그러나 조사한 규칙을 새 운영 전략으로 배포할 근거는 나오지 않았다. 이 보고서의 손익은 가상 계산이며 사용자의 실제 손익이 아니다. 기존 운영 전략이 검증되었다는 뜻도 아니다.

## 1. 확보한 자료와 검증 범위

Binance 공식 USD-M BTCUSDT 무기한 선물의 2023년 1월부터 2026년 9월까지 45개월 자료를 내려받았다. 원본 1분봉 **1,971,360개**, 공식 5분봉 및 기간별 펀딩비율이 대상이다. 현물 가격으로 선물 성과를 계산하지 않았다. 다만 거래소는 LBank가 아니므로 LBank 체결 및 경고 품질을 인증하는 자료로 사용할 수 없다.

월별 ZIP 135개(1분봉·5분봉·펀딩 각 45개)는 공식 CHECKSUM의 SHA256과 대조했다. 1분봉을 5분봉으로 집계해 공식 5분봉과 비교했고, 불일치 날짜의 일별 아카이브를 추가 확인했다. 모든 날짜를 별도 체결 자료로 검증한 것은 아니다.

| 구간 | 원본 1분봉 | 제외한 1분봉 | 사용한 1분봉 | 용도 |
|---|---:|---:|---:|---|
| 2024-01~2026-09 | 1,445,760 | 25 | 1,445,735 | 개발·검증·첫 최종 평가 |
| 2023-01~12 | 525,600 | 110 | 525,490 | 추가 진입 전략의 별도 과거 구간 확인 |
| 합계 | 1,971,360 | 135 | 1,971,225 | 두 자료 묶음의 합계 |

가격이나 거래량이 충돌한 5분 구간은 어느 쪽 가격이 유리한지 선택하지 않고 모두 제외했다. 제외 구간 이후 지표의 연속 이력을 새로 쌓았고 가격을 보간하지 않았다. 2024~2026년에는 5개, 2023년에는 22개의 5분 구간을 제외했다. 정확한 시각과 원본 출처 해시는 `integrity_final_*.json`에 있다. 체크섬 일치는 내려받은 바이트의 무결성을 뜻하며 시장 데이터가 완벽하다는 증명은 아니다.

무결성 검사 초기 초안에서 ‘월별 1분봉과 일별 1분봉 비교’라고 표시한 항목이 실제로는 5분 집계 비교였다. 원본 1분봉 비교로 수정하고 재검사했다. 2024~2026년의 제외 구간은 동일해서 이미 계산한 성과는 바뀌지 않았다. 2023년 평가는 수정된 검사로 추가 불일치를 제외한 뒤 수행했다. 초안 파일은 삭제하지 않았다.

## 4. 손익과 진입을 계산한 방법

완료된 봉만으로 신호를 만들었다. 최초 세 전략은 5분봉 완료 후 발행 지연 1초를 가정하고, 그 뒤 첫 1분봉 시가를 진입 가격으로 삼았다. 실제 호가나 발행 지연을 측정한 것은 아니다. 다음 원본 분봉의 고가·저가를 따라가며 같은 분 안에서 손절과 목표가가 모두 닿으면 손절을 먼저 처리했다. 데이터가 끊기면 수익을 추정해 채우지 않고 미확정으로 남겼다.

기본 계산은 편도 수수료 0.06%, 불리한 편도 슬리피지 0.02%다. 실제 LBank 계정 수수료를 조회한 값은 아니다. 스트레스 계산은 이 둘을 2배로 했다. 보유 중 기록된 펀딩비율을 사용하되 유리한 수취는 반영하지 않았고, 정산 가격은 거래 가격을 대용했다. 따라서 펀딩비율은 역사적 관측값이지만 실제 계정의 정산 금액을 재현한 것은 아니다.

`1R`은 해당 거래의 원래 손절까지 예상 순손실액이다. 평균 순손익 -0.40R은 이 단위로 평균 손실이 0.40이라는 뜻이며 계좌 수익률 -40%라는 뜻이 아니다. PF는 순이익 합계/순손실 절댓값 합계이며 1을 넘어야 표본 내 순이익이다. 목표 도달률과 순수익 거래 비율을 별도로 기록했다.

세 전략은 각각 독립적으로 한 포지션, 최소 진입 간격 45분, 하루 최대 8회, 최대 보유 2시간으로 평가했다. 연구의 일별 제한은 UTC 기준이며 운영 알람의 KST 정책과 다르다. 고정 가격 진입 실험은 계획 유효시간 15분, 지정가 0.1ATR 관통, 진입한 첫 분의 목표 도달 수익 불인정, 불리한 갭 반영을 적용했다. 지정가 대기열·체결량은 검증하지 못했다.

추가 실험에는 목표 전 이익 보호도 넣었다. 실제로 관측된 분봉 종가의 유리한 움직임만 사용하고, 새 보호 가격은 다음 분부터 적용했다. 보호 가격을 소급해 이익을 만들지 않았다. 돌파 갭으로 원래 손절 한도를 넘은 거래도 기록에 남겼다.

**목표 도달이 50%를 넘는 후보도 전체 순손익은 손실이었다.** 이는 알람의 적중 여부 하나로 우위를 판정하면 안 된다는 실제 계산 결과다. 손절 폭에 비해 목표까지 얻는 이익이 작고, 실패 시 손실을 회수할 만큼 유리한 경로가 충분하지 않았다. 아래 원장에는 진입·목표·손절 가격, 종료 사유, 순손익이 함께 있다.

고정 HGB 순손익 예측 모델로 걸러 보아도 2025년에는 선택 0건, 2026년에는 2건에 그쳤다. 두 거래의 평균은 -0.078R이었다. 거래 수 부족과 음수 결과로 인해 채택할 근거가 없었다. 알람을 거의 없애는 것을 성능 개선으로 평가하지 않았다.

## 8. 운영 판정과 남은 한계

새 진입 규칙 6개, 고정 선택 모델, 별도 시간봉 방향 모델에서 운영 교체를 정당화할 근거를 얻지 못했다. 이번 연구의 범위 안에서는 **채택 0개**다. 연구 브랜치만 기록하고 운영 전략을 새 후보로 교체하지 않았다. 확인한 Railway 운영 배포는 `139c23d12fa2783743aaa7463ff810e1ccfe0478`의 SUCCESS 상태다. 이 기존 배포의 목표 전 보호 기능과 이번 신규 전략의 우위 검증은 별개다.

현재 연구는 운영 전체 전략을 같은 자료에 정확히 재현한 비교 실험이 아니다. 첫 실험은 구조적 목표에서 전량 종료하며 운영의 부분 청산·잔여 포지션과 다르다. 긴급 경고까지 포함한 실제 LBank 발신 이후의 경로와 실제 체결을 이 자료로 인증할 수도 없다. 따라서 ‘새 후보가 현재 운영보다 몇 % 낫다’는 수치를 내지 않았다.

성과가 나쁘다는 사용자의 관찰을 수수료 하나로 설명하지 않는다. 이 자료에서 확인된 문제는 고른 진입 조건이 순손익이 유리한 경로를 충분히 구별하지 못했다는 것이다. 손절 폭·목표 폭·진입 후 경로의 관계를 개선했다는 증거 없이 지표를 추가하거나 확인을 더 기다리는 변경은 채택하지 않았다.

후속 후보를 평가하려면 이제 관측한 2026년 구간을 새 최종 표본처럼 재사용해서는 안 된다. 고정 규칙과 사용 가능한 별도 자료, LBank 원본의 발신 시점·실제 가격 경로 검증이 필요하다. 이 보고서는 그 단계가 완료됐다고 주장하지 않는다. 손절이 전혀 없는 전략이나 일일 일정 수익을 입증한 자료도 확보하지 못했다.

## 9. 파일과 재현 방법

코드는 `research/long_history/`, 집계 결과와 출처는 그 아래 `results/`에 있다. 거래별 압축 CSV는 별도 제공하는 검증 자료 ZIP에 포함한다. 용량이 큰 원본 시장 ZIP은 자료 묶음에 중복하지 않았으며 공식 URL과 SHA256으로 다시 받을 수 있다. `evidence_manifest.json`은 포함한 모든 파일의 해시를 제공한다.

```bash
python -m pip install -r research/long_history/requirements.txt
export PYTHONPATH=.
export OMP_NUM_THREADS=2
export OPENBLAS_NUM_THREADS=2
python research/long_history/download_binance.py --folder /tmp/btc-main --start 2024-01 --end 2026-09 --interval 1m
python research/long_history/download_binance.py --folder /tmp/btc-main --start 2024-01 --end 2026-09 --interval 5m --funding
python research/long_history/audit_integrity.py /tmp/btc-main
python research/long_history/evaluate.py --folder /tmp/btc-main --output /tmp/btc-main-result
python research/long_history/entry_location.py --folder /tmp/btc-main --output /tmp/btc-planned-result --integrity /tmp/btc-main/integrity_audit.json
python research/long_history/download_binance.py --folder /tmp/btc-blind --start 2023-01 --end 2023-12 --interval 1m
python research/long_history/download_binance.py --folder /tmp/btc-blind --start 2023-01 --end 2023-12 --interval 5m --funding
python research/long_history/audit_integrity.py /tmp/btc-blind
python research/long_history/entry_location.py --folder /tmp/btc-blind --output /tmp/btc-blind-result --integrity /tmp/btc-blind/integrity_audit.json
python -m unittest test_lbank_long_history test_lbank_entry_location
```

공식 아카이브가 나중에 수정되면 현재 내려받은 버전과 해시가 달라질 수 있다. 저장한 출처 명세와 비교해야 한다. 집계 보고서에 덧붙인 포장 정보·라이브러리 버전은 평가 후 기록했으며, 압축 CSV는 내용 변경 없이 gzip 시간값을 0으로 정규화했다. 환경 차이로 부동소수점 끝자리가 달라질 수 있다.

LBank 관련 구현 테스트 350개가 통과했다. 이 중 새 장기 검증 관련 테스트는 16개다. 이는 시점 처리와 계산 구현을 점검한 결과이며 수익성을 통과했다는 뜻이 아니다.
