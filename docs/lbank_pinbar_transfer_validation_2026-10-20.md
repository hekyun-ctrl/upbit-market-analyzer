# 공개 1분봉 핀바 규칙의 실제 가격·비용 전이 검사

**결론: 이 고정 규칙의 선물 전이 버전은 대체 알람에서 제외한다.** 기본·두 배 비용에서 두 지연 모형 모두 순손실이었다. 원전 현물 실행기를 그대로 복제한 결과나 모든 핀바 기법에 대한 판정은 아니다. 기존 운영 전략의 손실 원인을 이 결과로 대체하지 않는다.

## 원전과 사전 고정

[원전 기사](https://rlxbt.com/articles/the-1-minute-liquidity-hunt-discovering-the-ultra-sharp-pinbar-rejection-wick-85-range-03-on-21m-btc-bars)는 2026-09-09 공개됐다. 원문 가격·거래량 조건, 손절0.35%, 목표0.70%, 최대25봉을 유지했다. ‘wick’라는 명칭과 달리 공식은 봉 안에서의 종가 위치다. 이를 연구자가 다른 꼬리 공식으로 고치지 않았다. 저자가12개 가설에서 고른 성과와 비용 모형 불명확성을 인정하며, 제목의 양수를 검증 결과로 사용하지 않았다.

- [규약·코드 고정 커밋](https://github.com/hekyun-ctrl/upbit-market-analyzer/commit/378586d9d5bf07859e2b3fb999fed9a86aec4987): 손익 계산 전 규칙·기간·비용·지연·통계·공백 처리를 저장했다.

## 자료와 거래 모형

Binance USD-M BTCUSDT **2024-01-01~2026-09-30 전체 1,004일**, 1분봉1,445,760행과 펀딩3,012행을 사용했다. 소비한 ZIP66개의 SHA를 기존 Git manifest와 별도로 다시 대조했다. 누락·중복 분봉0개이며 기존 미해결 불일치5구간의25분을 격리했다. 이번 거래는 공백에 걸린 미상 종료0건이었다. 코드와 검사에는 공백·자료 끝의 미상 처리 반례가 있으며 임의 청산을 하지 않는다.

**전 기간이 이미 관측된 탐색 자료**다. 원전은 현물이고 이번 자료는 선물이므로 거래량 분포도 다르다. 원전 원본자료 복제·독립 미관측 검증·LBank 체결 성과로 바꾸어 표현하지 않는다. 한 고정 규칙의0분/추가1분 지연 민감도 검사이며 두 표본은 서로 겹쳐 독립 전략·독립 거래 집합으로 합치지 않는다.

완료봉 뒤 시가에 진입하며 같은 봉 진입 직후 손절도 반영한다. 같은 분봉에서 목표·손절이 모두 닿으면 손절 우선, 손절 갭은 불리한 시가, 최대25봉 종료는 종가를 사용한다. 보호선과 거래 경로를 고정하고 편도 수수료0.06%·불리한 체결0.02%·과거 펀딩 지급 모형을 모두 두 배로 스트레스한다. 펀딩은 Binance 과거 결제율에 마지막 관측 분봉 시가를 대입한 지급액이며 수취는0으로 둔다. 실제 LBank 수수료·마크 가격·수동 체결이라고 주장하지 않는다. 레버리지·사용자 계정 배분·허용 손실 확대를 적용하지 않았다.

1R은 이 계산에서 기준 진입가의0.35%인 단위 위험이다. R 합계는 순차 거래의 진단 척도이며 복리 계좌 수익률이나 사용자 실제 손익이 아니다. 포지션 배분·파산 이후 운용을 모사한 계좌 백테스트가 아니다.
