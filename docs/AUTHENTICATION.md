# 인증, 요청 흐름 및 토큰 처리

## 구성요소

| 구성요소 | 인증 방식 | 보유하는 정보 |
|---|---|---|
| ChatGPT/Codex MCP 클라이언트 | 배포된 MCP URL에 연결 | MCP 세션 정보 |
| Railway MCP 서버 | 현재 공개 읽기 전용 | 공개 시세 응답만 일시 처리 |
| Upbit Quotation API | 해당 공개 엔드포인트에 개인 키 미사용 | 공개 마켓 데이터 |
| GitHub | GitHub App/OAuth 연결을 플랫폼이 관리 | 저장소 권한 토큰(코드에 전달 안 됨) |
| Railway | GitHub 배포 연결을 플랫폼이 관리 | 배포 권한(코드에 저장 안 됨) |

## 요청 흐름

1. 사용자가 ChatGPT에서 시장 조회나 분석을 요청합니다.
2. ChatGPT가 `/mcp`에 MCP 도구 호출을 보냅니다.
3. 서버는 마켓 형식과 캔들 간격·개수를 검증합니다.
4. 서버가 고정된 `https://api.upbit.com` 공개 경로로 HTTPS GET 요청을 보냅니다.
5. 업비트 공개 JSON 응답을 필요한 필드만 추려 계산합니다.
6. 결과와 투자 판단 유의문구를 MCP 응답으로 반환합니다.

## 자격증명과 토큰

### 업비트

`Authorization` 헤더를 만들지 않으며 Access Key, Secret Key, JWT, nonce를 사용하지 않습니다. 환경변수에도 업비트 개인 키 항목이 없습니다.

### GitHub 및 Railway

GitHub App/OAuth 토큰과 Railway의 배포 자격증명은 플랫폼 연결 계층에서 사용됩니다. 애플리케이션 프로세스에는 이 토큰이 필요하지 않으며 저장소 파일에 기록하지 않습니다.

### MCP 접근 제어

현재 기능은 인터넷에서 이미 공개된 시세만 반환하므로 별도의 사용자 계정 인증을 두지 않습니다. 향후 사용자별 데이터나 쓰기 기능을 도입한다면 이 설계와 별도 서비스로 분리하고 OAuth 2.1 기반 인증, 최소 권한, 토큰 만료·회전을 적용해야 합니다. 업비트 주문 기능은 이 서버에 추가하지 않는 것을 원칙으로 합니다.

## 로그와 오류

토큰과 환경변수 값을 로깅하지 않습니다. 업비트 오류 본문 전체를 사용자에게 그대로 노출하지 않고 상태 오류로 처리합니다. 공개 API 데이터는 요청 처리 동안만 메모리에 존재하며 데이터베이스에 저장하지 않습니다.
