# 추가 원인 분해와 재설계 실험 — 2026-10-20 KST

**상태: 추가 검증은 실행했지만, 양의 순손익이 확인된 운영 교체안은 아직 없다. 성능 개선 완료가 아니다.**

‘대안이 실패했다’는 앞선 보고 이후, 실제 알람의 실패 경로와 진입·청산의 영향을 분리했다. 기존 연구 후보를 그대로 둔 청산 비교, 가격 정보와 체결 흐름 정보의 비교, 기존 후보 목록과 독립적인 진입 생성기 두 개를 추가 실행했다. 모든 결과와 계산 코드를 남긴다. 나쁜 결과를 제외하거나 수익 후보가 나올 때까지 같은 기간의 기준을 재조정하지 않았다.

## 1. 실제 운영 코드와 알람에서 확인한 문제

운영의 `minimum_net_rr_target()`는 손절의 예상 순손실을 기준으로 순손익비 1.5배를 만족하는 목표 가격을 푼다. **이 함수는 목표에 도달할 확률을 예측하지 않는다.** 시장 구조·변동성 필터가 있어도 그 값이 보정된 성공 확률로 바뀌는 것은 아니다. 반대로 목표 가격을 단순히 가깝게 낮추면 손익이 좋아진다는 뜻도 아니다. 아래의 같은 진입 비교에서 직접 확인했다.

실제 과거 알람 5건을 분해했다. 모두 현재 `139c23d` 배포 이전 사례이므로 현재 보호 정책의 실패율로 쓰지 않는다. 다음 표의 유리한 움직임은 진입 후부터 첫 후속 전까지 **완전히 포함되는 5분봉**에서 관측한 값이다. 진입·후속이 속한 부분 봉과 공백은 채우지 않았다. 따라서 실제 최대 유리폭 전체나 실현 가능 수익을 뜻하지 않는다.

| 알람 | 목표 거리 | 첫 후속 전 관측 유리폭 | 확인 가능한 사실 |
|---|---:|---:|---|
| #8 | 0.668% | 판단 불가 | 5분 안에 무효화. 사이에 완전히 포함된 5분봉이 없다. 기존 별도 감사에서는 이후 목표 도달을 관측했다. |
| #9 | 0.962% | 0.932% | 목표 가까이 움직였지만 중간 공백이 있어 전체 경로를 확정하지 않았다. |
| #10 | 0.759% | 0.136% | 확보된 후속 전 완전한 봉에서는 목표에 크게 못 미쳤다. |
| #11 | 0.700% | 판단 불가 | 약 7분 뒤 손절선 경고. 부분 봉을 제외하면 완전한 5분봉이 없다. |
| #12 | 0.780% | 0.481% | 상당한 유리한 움직임 뒤 목표 미달·역행. 관측한 방향 일치가 수익 실현으로 이어지지 않았다. |

이 표만으로 모든 손실이 같은 원인이라고 결론 내리지 않는다. #12는 목표 전 보호 문제를 보여 주고, #11은 잘못된 진입을 보호 장치만으로 해결할 수 없다는 경고 사례다. #8·#11의 ‘판단 불가’를 유리한 움직임 0으로 집계하지 않는다. 실제 거래소 손절 체결이나 사용자 체결을 알람 로그로 대신하지 않는다.

## 2. 진입을 고정한 청산 비교

사전 기록: `ed02e0428a10c34bd2afaefe784b01ebbd8486c3`.

기존 연구 후보 **8,555건**을 재사용했다. 먼저 원래 청산 결과가 원장과 일치하는지 확인한 뒤, 원래 선택한 포트폴리오의 진입 순서를 그대로 사용했다. 새로운 이른 진입이나 추가 진입으로 개선을 만들어 내지 않았다. 원래 손절을 유지하고, 새 목표는 원래 목표보다 멀어지지 않게 했다. 이 비교는 운영 전체의 정확한 재현이 아닌 기존 세 연구 후보의 통제 실험이다.

보호 규칙은 분봉 종가의 순수익이 0.5R 이상인 뒤 관측 최고 순수익의 25%를 보호하며, 0.5ATR 여유·5분 갱신 간격·0.25ATR 개선 폭을 요구했다. 새 보호 가격은 다음 분부터만 유효하다. 같은 분에서 목표와 손절이 겹치면 불리하게 처리했다. 비용과 원래 위험액은 앞선 검증과 같다.

| 2026년 1~9월, 같은 완료 거래 1,507건 | 평균 순손익 | PF |
|---|---:|---:|
| 원래 목표·손절 | -0.3761R | 0.2837 |
| 원래 목표 + 앞선 수익 보호 | -0.3727R | 0.2776 |
| 목표를 최대 0.5 순R로 제한 + 보호 | -0.3761R | 0.2650 |
| 목표를 최대 1.0 순R로 제한 + 보호 | -0.3704R | 0.2821 |

2025년 2,043건에서도 네 방식 모두 음수였다. 작은 수치 차이를 ‘성능 개선 성공’이라고 부르지 않는다. **목표를 낮추거나 이익 보호를 앞당기는 변경만으로 기존 후보를 수익 전략으로 바꿀 근거는 없었다.** 목표가 다른 실험의 목표 도달률을 같은 알람 정확도로 비교하지 않았다.

R은 원래 예상 순손절액을 1로 둔 단위이며 계좌 수익률이 아니다. 비용이 포함된 실제 사용자 손익도 아니다.

## 3. 체결 흐름을 추가한 선별 실험

완료된 원본 분봉의 공격적 매수·매도 거래량 차이, 5·15·60분 지속성, 거래대금과 거래 수, 거래당 크기를 추가했다. 가격 지표만 사용하는 모델과 같은 설정의 HGB 모델로 비교했다. 2025년 예측은 2024년으로, 2026년 예측은 2024~2025년으로 학습했고 경계 하루를 제거했다. 예상 순손익 0.10R 초과라는 기준은 결과를 보고 바꾸지 않았다.

원래 포트폴리오의 같은 진입 기회 중 가격 모델은 2025년 0건, 2026년 1건을 선택했고 해당 1건은 -1R이었다. 체결 흐름 추가 모델은 두 구간 모두 0건이었다. **거래를 없앤 모델을 높은 품질의 알람으로 평가하지 않는다.** 모델이 성공 확률을 보정했다고 주장하지도 않는다.

이 체결 흐름은 Binance 관측치다. LBank의 실제 체결 흐름이나 호가 대기열·청산 규모로 부르지 않는다. 실제 LBank 발신에 사용할 수 있는 데이터 연결을 완료한 실험도 아니다.

## 5. 무엇을 결론 내릴 수 있는가

기존 진입 후보를 청산 변경과 추가 체결 특징으로 고치는 접근, 이번에 새로 정한 두 진입 규칙 모두 채택 근거가 없었다. **기존 운영의 진입 우위가 입증됐다는 근거도 여전히 없다.** 목표 전 보호 수정과 신호의 통계적 우위는 별개다. 지금의 운영 알람을 ‘검증된 높은 정확도의 진입’이라고 설명할 수 없다.

모든 2024~2026년 결과는 이미 관측한 자료를 다시 활용한 **탐색 결과**다. 학습·예측의 시간 순서를 지켜도 연구자의 이전 관측이 사라지는 것은 아니다. 이번 결과를 새로운 독립 최종 검증으로 표시하지 않는다. 실패한 후보를 새 구간에 가져가 성공처럼 만들지 않았으며, 2022년 별도 구간은 이번에 확보·검증했다고 주장하지 않는다.

운영 교체와 수익성 입증은 **미완료**다. 이 단계에서 수익을 약속하거나, 손절 폭·증거금을 늘리거나, 경고를 숨겨 성과를 좋게 만들지 않았다. 연구 실행만으로 사용자가 요청한 ‘획기적인 알람 개선’을 달성했다고 보고하지 않는다.

다음 단계에서 해결해야 할 핵심은 진입·목표·손절의 조합에 대해 **실제 접근 가능한 정보로 관측하지 않은 구간의 양의 순손익을 입증하는 것**이다. 가격의 큰 방향을 잠깐 맞히는 것, 목표를 계산하는 것, 코드 테스트가 통과하는 것으로 대체할 수 없다. 시간과 자료가 필요한 검증을 오늘 완료한 것처럼 축약하지 않는다.

## 6. 재현과 자료

`research/long_history/`의 새 코드:

- `native_failure_decomposition.py`: 위 실제 5건의 관측 경로 분해.
- `exit_intervention.py`: 같은 진입 기회에서 청산과 체결 특징을 비교.
- `independent_structures.py`: 별도 두 진입 생성기.
- `*_protocol_20261020.json`: 결과 전에 저장한 계획.
- `results/*intervention*`, `results/independent_structure_report.json`, `results/native_failure_decomposition.json`: 모든 집계 결과.

추가 구현을 포함한 연구 테스트 21개가 통과했다. 이는 수익성 인증이 아니다. `follow()`에 6시간 실험을 위한 선택적 보유시간 인자를 추가했으며 기존 실험의 기본 120분과 계산은 유지했다. 보호 가격의 소급 적용 금지, 미래 가격이 이전 신호·체결 특징에 영향을 주지 않는 점을 검사했다.

```bash
export PYTHONPATH=.
export OMP_NUM_THREADS=2
export OPENBLAS_NUM_THREADS=2
python research/long_history/native_failure_decomposition.py
python research/long_history/exit_intervention.py --folder /tmp/btc-main --labels /tmp/btc-main-result/labelled_development_and_test.csv.gz --selected /tmp/btc-main-result/selected_trades.csv.gz --output /tmp/btc-exit-result
python research/long_history/independent_structures.py --folder /tmp/btc-main --integrity research/long_history/integrity_final_2024_2026.json --output /tmp/btc-new-result
python -m unittest test_lbank_exit_intervention test_lbank_long_history test_lbank_entry_location
```

체결 흐름과 가격 예측의 연구 단서로 [Kim·Hansen, The Quarter-Hour Effect](https://arxiv.org/abs/2607.09426)를 검토했다. 논문은 첫 10초의 흐름을 다루며 비용 차감 후 거래 전략을 인증하지 않는다. 위 1분봉 실험을 해당 논문의 정확한 재현이나 수익성 증명으로 부르지 않는다.
