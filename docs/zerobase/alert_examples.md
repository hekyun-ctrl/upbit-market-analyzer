# 합성 입력 알림 예시

아래는 현재 시세가 아닌 동작시험용 숫자이며 외부 발신하지 않았습니다.

```text
[모의 검증 | BTCUSDT 선물 | LONG | 추세 되돌림]
판정 2026-10-21T16:00:00+09:00 / 데이터 2026-10-21T16:00:00+09:00 / 만료 2026-10-21T16:02:00+09:00
진입 범위 99.40~100.60 / 체결 추정 100
손절 96 LAST / 5분 종가 무효화 97
1차 106.0: 25% / 잔여75% ATR2 추적 / 다음 참고 112
가상 시드 1000 USDT / 계획 위험 2.499990220 USDT(최대0.25%) / 참고 BTC 0.62195
비용후 목표 손익비 1.487560951338441635983679968 / 비용 ASSUMED_SYNTHETIC:fixture_only
근거 추세 되돌림 / 상충·자료 상태는 사건 기록 참조
ZB-1.0:BTCUSDT:TREND_PULLBACK:1:1792565700 / ZB-1.0
```

주의: 상위 장세 전환, 원래 구조 유지 — 즉시 종료와 구분.

무효화: 진입 이후 시작한 완료5분봉 종가가 원래 I 이탈.

손절: LAST 기준 유효 손절 도달, 반등해도 사건 보존.

부분 익절: 25% 청산, 잔여75% ATR2 추적.

자료 장애: 새 진입 보류, 가능한 가격 위험 감시 유지.
