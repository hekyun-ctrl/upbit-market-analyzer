# 엘뱅크 BTCUSDT 5분봉 조기 후보 감사 장부 (2026-11-11)

## 목적과 범위
- 최근 약 일주일 간 전용 영상 알람의 조건부 진입 발송이 없었다는 운영 이슈에 대응한다.
- 엘뱅크 영상 알람 코드에 **연구·관찰 전용** 후보 기록을 추가한다. 기존 RSI/CCI 전략, 호가·비용·손절·목표 조건, 텔레그램 전송, 주문 로직은 바꾸지 않는다.
- 사용자에게 매매 신호로 발송하지 않고, VIDEO_EARLY_AUDIT 운영 로그와 기존 전용 서비스의 영속 SQLite에 기록한다.

## 독립적인 조기 후보 규칙
최신 **완료된** BTCUSDT 5분봉의 종가가 이전 6개 완료봉 고가의 최댓값을 초과하면 롱 후보, 이전 6개 완료봉 저가의 최솟값보다 낮으면 숏 후보로 본다.
거래량은 **현재 신호봉을 제외한** 이전 20개 완료봉 거래량의 중앙값 대비 1.5배 이상이어야 한다.

- candidate: 가격 돌파와 거래량 기준 동시 충족
- breakout_below_volume_threshold: 가격 돌파했으나 거래량 기준 미달
- no_breakout: 가격 돌파 없음
- insufficient_history: 이전 봉이 20개 미만
- invalid_source: 완료봉·연속성·원문 OHLCV·마감 수신 시점 검증 실패
- missing_volume_baseline: 거래량 중앙값이 0

이 규칙은 **초기 움직임 관찰용**이며 손익비 충족, 추세 전환, 추천 진입 또는 수익성을 의미하지 않는다.

## 데이터/영속성
- 입력: 기존 영상 알람 함수가 읽는 연속 stream_closed 5분봉. 이 봉은 엘뱅크 WebSocket의 1분봉을 합산하여 *스트림 진행으로 완료 추정*한 자료이며 REST 독립 완료 확인은 없다.
- 저장: 기존 video_alert_delivery.sqlite3의 새 테이블 video_early_breakout_audit에 완료 5분봉 시각별 **첫 관측값만** 저장한다 (INSERT OR IGNORE).
- 보존: policy, 판정 시점, 조기 상태/방향, 봉 가격·거래량·배율, 6봉 장벽, 입력 해시, 기존 최종 진입 판정 final_status, final_reasons, 자료 한계를 기록한다.
- 독립성: 감사 장부 쓰기가 실패하더라도 기존 Telegram/진입 판정이 변경되거나 다시 발송되지 않는다. 실패는 VIDEO_EARLY_AUDIT_FAILURE로 기록한다.
- 새 후보 기록은 5분마다 평가된 실제 봉만 기록한다. **기존 과거 로그를 거래 이력인 것처럼 역으로 삽입하지 않는다.**
- 별도 조기 후보의 텔레그램 발송, 주문, 신규 포지션 생성 기능은 없다.

## 사전 분석 근거와 한계
2026-11-04~10의 Railway 운영 기록에서는 완료 5분봉 약 1,833개를 확인했고, 단순한 이전 6봉 돌파와 거래량 1.5배 기준으로 약 218건의 조기 후보가 확인됐다. 해당 후보 중에는 같은 방향으로 연달아 발생한 여러 봉이 포함될 수 있다.
반면 기존 조건부 진입 Telegram 수락 로그는 확인되지 않았고 다수의 실행 결과가 no_qualified_entry였다.
**218건은 수익 거래 횟수도, 서로 독립된 거래 횟수도 아니며 실거래 성과로 사용하지 않는다.** 별도 조기 후보 장부는 배포 이후부터 생성된다.

## 테스트 및 단계별 검증
기존 서비스의 Railway 사전 시험에 test_lbank_early_breakout_audit를 추가했다.

개발 환경에서 실행한 새 모듈 시험: 8개 통과.
python -m unittest -v test_lbank_early_breakout_audit

확인 항목: 롱/숏 돌파, 거래량 경계값, 미래·현재봉 기준량 제외, 저거래량 탈락, 가격 접촉은 신호 아님, 미완성/불연속 봉 차단, 준비 부족/0 거래량, 재시작 중복 방지 및 기존 최종 탈락 사유 연결.

운영 반영 전 단계:
1. PR 검토 및 기존 영상 알람 시험·추가 회귀 시험 통과.
2. 비생산 환경에서 신규 장부 기록과 VIDEO_EARLY_AUDIT 매 5분 로그 대조.
3. 새 장부의 독립 후보/기존 최종 조건/이후 가격 경로를 거래별로 비교. 중복 후보·스프레드·체결·펀딩 비용·슬리피지·50배 레버리지 위험을 별도 계산.
4. 검증 이후 실시간 후보 알림을 검토하되, 사용자 승인 없이 **미검증 후보를 실거래 알람으로 승격하거나 주문하지 않는다**.
