배포용 브랜치 `feature/lbank-video-alert-20261104`의 시작 명령은 `python -u lbank_video_alert.py`다.
운영 브랜치에 병합하지 않는다. ZB, 모의 알람, 업비트, 계정 및 자동주문과 연결하지 않는다.

RSI 반전형과 볼린저밴드·CCI 추세 지속형을 각각 평가한다. 두 조건이 동시에 필요한 것은 아니다.
판단은 실제 수신 시각이 있는 최근 연속 완료 5분봉이 40개 준비되면 시작하고,
봉 마감 후 30초가 지나면 해당 봉의 알람을 보내지 않는다. 끊긴 구간과 5분 스냅샷을 보간하지
않는다. 원본 공급자는 엘뱅크이며, 5분봉은 연속 1분 업데이트에서 합산한 것으로 거래소의
독립 원본 5분봉 및 거래량 단위가 따로 검증됐다는 의미는 아니다. 거래량은 같은 스트림 안의
상대 비교에만 사용한다.

기존 [영상 전략 연구](VIDEO_ENTRY_20261104.md)의 비용 후 손익비 1.5와 고정 목표·손절을 유지한다.
조건을 통과하면 엘뱅크 선물 공개 호가를 새로 조회한다. 5초 이내 응답과 0.05% 이하 스프레드,
실제 1호가의 추격 한도 및 손익비를 모두 확인한다. 호가 데이터의 거래소 시각이 제공된다는
가정은 하지 않으며 요청 지연만 측정한다. 두 후보가 반대 방향이면 발송을 보류한다.
같은 방향이 겹치면 현재 호가에서 비용 후 손익비가 큰 계획으로 한 번만 보낸다.

전용 `/data` 볼륨에 봉·발송 상태를 기록한다. 알람 전 봉 키를 먼저 예약하며, 재시작 후에도
이전 신호와 전송이 불확실한 메시지를 재발송하지 않는다. `VIDEO_ALERT_SEND_ENABLED=1`이
지정된 전용 서비스에서만 전송한다. `VIDEO_ALERT_TELEGRAM_BOT_TOKEN`과
`VIDEO_ALERT_TELEGRAM_CHAT_ID`는 기존 알람 연결을 참조하는 Railway 변수이며 값은 코드에
저장하지 않는다. 시작 시 조회 권한만 확인하며 시험 메시지를 전송하지 않는다.
