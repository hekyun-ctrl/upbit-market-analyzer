## 자료와 고정 규칙
진입 구간 UTC 2025-01-08 00:00 ~ 2025-01-15 00:00 미포함, 종료 추적 2025-01-16 00:00까지. ZB 예열은 1월5일부터. 기존 연구에서 이미 본 구간이며 독립 표본이 아니다. 자료는 Binance USD-M BTCUSDT 공개 월별 1분 44,640개, 별도 5분 8,928개, 펀딩 93개다. LBank 원본 자료가 아니며 실제 체결 성과로 전환하지 않는다.

원본 URL·SHA256·공식 CHECKSUM 일치는 `research/zerobase/comparison_20261022/source_manifest.json`에 있다. 별도 5분과 1분 집계의 가격 불일치 2건은 `crosscheck_mismatches.json`에 원형 보존했다. 자료를 고쳐 수익을 만들지 않고 ZB의 기존 자료 차단 경로에 전달했다. 초기 실행은 이 불일치에서 assertion으로 중단됐으며, 최종 실행은 불일치를 기록하고 실제 엔진의 차단 처리를 유지한 채 종료했다.

기존 기준 소스 25388b431c9c9d38df6a434670586c65f382d604. ZB 승인 소스 06b88b94a6b5ff0ab5fda0ed0c08a03bc5faa03b. core/engine/monitor 로컬 Git blob SHA가 연구 브랜치와 일치함을 확인했다. 모니터의 기준 대비 차이는 시작 훅·모의 알림 기본값뿐이며 classify/confirm/기존 관리 함수 변경은 없다. 실행 파일 SHA는 `code_manifest.json`에 보존했다. 전체 ZB 기능시험 42개 통과는 수익성 증거가 아니다.

## 비용·체결의 실제 한계
두 쪽 비용 재평가에 왕복 각 6bp taker, 진입·종료 각 2bp 불리한 미끄러짐, 실제 Binance 펀딩 이력을 사용했다. 이 수치는 LBank 계좌 요율을 인증한 것이 아니다. ZB tick0.1, 수량단위0.001BTC, 최소주문5USDT는 명시적 모형 가정이며 채택 근거가 아니다. ZB 계획 펀딩 준비금은 당시까지 공개된 선행 펀딩률 절댓값 최대치로 한 회분을 준비했으며 30일 이력은 확보하지 않았다. 향후 펀딩률은 진입 판단에 사용하지 않았다.

기존 진입은 기존 코드의 신호 시세, ZB는 고정된 60초 지연을 사용하므로 공통 수동 체결 지연을 맞춘 완결 비교가 아니다. 기존 관리는 1분 시작가로 재생하고 봉 내 순서를 모르면 기존 코드대로 검열했다. 13건 중 intrabar stop4·profit guard9건. 두 배 비용은 동일 경로 재평가이며 두 배 비용으로 진입·출구를 재판정한 전체 재실행이 아니다. 양쪽의 포지션 중첩·일별 위험 정책도 서로 다르다. 부트스트랩 수치가 JSON에 있어도 무거래·검열·체결 조건 차이 때문에 개선 추론은 불가(`inference_admissible=false`).

## ZB 무진입 원인
예열·추적을 포함하면 후보136건 전부 비용비율·목표 순손익비 조건에서 거절됐다. 평가 진입 구간의 후보 수와 거절 원인은 원본 `zb_events.json`의 시각별 사건으로 분리 가능하다. 일부에는 진입 범위·자료 불일치 조건도 겹친다. 단순 대기 시간이 지나면 해결되는 문제가 아니므로 기존 기준을 완화하거나 알림을 늘려 성과로 취급하지 않는다.

## 모의 알림 중지 요청
`STOP_PAPER_NOTIFICATIONS.json`에 중지 의도를 고정했다. Railway describe_service는 `UNAUTHORIZED / oauth_token_invalid_grant`로 실패해 운영 적용·중지 완료를 확인하지 못했다. 과거 내부 장애와 현재 연결 인증 장애는 서로 다른 문제다. 필요한 설정은 LBank 서비스에만 `LBANK_PAPER_NOTIFICATIONS_ENABLED=false`, `LBANK_ZB_RUNTIME_ENABLED=false`. 기존 참고·무효화·위험 알람 경로는 유지한다. 배포 복구 예약에도 최신 중지 지시를 반영하여 향후 배포 때 모의 발신을 재개하지 않도록 했다. 비밀값 조회·주문·타 서비스 변경 없음.
