# RSI 쌍바닥·쌍봉 알람 보완 — 검토용

## 우주심 직접 테스트 요청에 따른 실발송 전환

11월 5일 우주심이 새 RSI 신호를 직접 테스트하기 위해 알람을 요청했다.
이에 실행 서비스는 `video_live_rsi_two_turn_v2`를 사용한다. 새 RSI와 기존 독립
CCI가 실제 발송 대상이며, 새 RSI 문구에는 직접 테스트용·수익성 미검증을 표시한다.
이 결정은 수익성 검증 통과나 위험 기준 완화를 의미하지 않는다.

확정 완료봉의 새 신호에만 적용한다. 기존 관찰 장부를 소급 발송하거나 전환 전
신호를 재시도하지 않는다. 두 반전의 시각·극점 가격·목표 근거, 실제 비용 가정과
조회 호가를 발송 문구 및 영속 장부에 남긴다. 준비 사건 ID의 중복 예약을 유지하며,
재시작 이후에도 미확인 발송은 재시도하지 않는다.

아래 관찰 전용 통합 기록은 이전 단계의 내역이다. 기본 오프라인 비교 함수는
기존 방식으로 남겨 재현성을 보존하며 실행 서비스가 새 RSI 모드를 명시해 호출한다.

## 11월 5일 통합 범위

이하의 연구 규칙과 비교 결과는 PR #30의 기록이다. 최신 영상 알람 브랜치에서는
이 규칙을 `rsi_two_turn_v2_shadow`로만 평가한다. 실제 발송의 진입 기준은
기존 RSI와 독립 CCI를 사용한다. 관찰 평가에는 발송 함수나 발송 예약이 없다.
실발송 문구에는 기존 규칙이 확인한 극점과 목표 근거를 표시한다. 두 장악형
반전 시각이 포함된 새 규칙 문구는 장부 미리보기로만 저장한다.

WebSocket 호가 조회와 REST 대체 경로, 종목·신선도·스프레드·비용 검사는 그대로다.
같은 봉에 실발송 평가가 조회한 호가는 관찰 평가가 재사용한다. 그 조회가 없고
관찰 후보가 조건을 충족한 경우에만 같은 유효 시간 안에서 조회를 한 번 시작한다.
신호 마감 시각이 지난 과거 봉에 소급해 조회하거나 발송하지 않는다.

별도 SQLite 장부에 실제 판정과 관찰 판정을 정책별로 32일 보존한다. 실발송 예약은
기존 봉 단위 키에 기존 RSI의 첫 극점·방향 키를 더했다. 후보와 조회 호가·비용을
저장하며, 예약이 실패하면 발송하지 않는다. 텔레그램이 이미 접수한 뒤 장부 갱신이
실패하면 접수 결과는 운영 로그에 남기고 예약을 유지한다.

새 규칙의 실발송 전환에는 이전에 사용하지 않은 연속 완료봉과 실제 발송 전 호가로
거래별 비교가 필요하다. 이 통합으로 체결 정확도나 수익성 개선을 확정하지 않는다.

## 수정한 판단

롱 기준이며 숏은 반대다. 완료 5분봉에서만 순서대로 평가한다.

1. RSI(14) < 30이고 하단 밴드(20,2) **밖에서 종가 마감**. 하락 장악형 또는
   3개 연속 음봉이어야 준비 상태가 된다. 꼬리만 이탈하거나 경계에 닿은 경우는 제외한다.
2. 첫 상승 장악형 마감을 확인한다. 준비 이후 하락이 더 이어지면 첫 저점을 갱신한다.
3. 첫 반전 이후 새 음봉으로 눌림이 시작되어야 한다. V자 반등에 두 번째 바닥을 만들지 않는다.
4. 눌림의 최저점이 해당 봉의 밴드 안에 있고, 두 번째 상승 장악형이 마감되면 후보를 만든다.
   두 번째 저점이 첫 저점보다 낮아도 허용한다. 미래의 피벗 확인봉을 기다리거나
   미래 봉을 사용해 과거 알람을 소급 생성하지 않는다.
5. 같은 준비 사건에서 후보는 한 번만 생성한다. 비용 탈락 뒤 같은 바닥으로 계속
   재진입을 권하지 않는다. 발송 예약도 사건 ID로 중복 차단하며 재시작 뒤 유지한다.

영상에 없던 기존의 3~18봉·두 저점 1ATR 이내·중간 반등 0.5ATR 제한은 제거했다.
대신 준비 사건은 48봉(4시간) 뒤 만료한다. 이는 자막 규칙이 아닌 명시적 구현 가정이다.
새 과매도·밴드 밖 종가 패턴이 나오면 새 사건으로 시작한다.
영상의 원래 시간 단위는 1시간이며 5분봉 적용의 수익성은 입증하지 않았다.

### 중심선을 넘은 반등과 목표

기존 코드는 반등이 중심선을 넘으면 `center_already_reached`로 바로 제외했다.
이 조건을 없앴다. 중심선이 아직 진행 방향 앞이면 목표 후보로 유지하고, 이미 지났으면
앞쪽의 **확정된 미돌파 지지·저항**을 찾는다. 더 가까운 장벽을 건너뛰지 않는다.
목표가 없으면 `no_known_target`이며, 손절 거리의 3배라는 이유로 목표를 만들어내지 않는다.

기존 비용 가정과 위험 한도 유지:

- 편도 수수료 0.06%, 손절 미끄러짐 0.02%, 펀딩 예비 비용 0.01%.
- 비용 후 손익비 최소 1.5, 진입가 대비 손절 거리 최대 0.6%.
- 신호봉에서 손절·목표·허용 진입 한계를 고정한 뒤 최신 호가로 다시 검사.
- 완료 후 30초, 호가 응답 5초, 스프레드 0.05% 한도 유지.

CCI 돌파는 독립 경로로 유지했다. RSI와 CCI를 동시에 만족해야 하는 조건은 추가하지 않았다.
현재 CCI 경로는 일반 CCI와 거래량의 조합이며 영상의 비공개 '세력 CCI' 재현이 아니다.
1시간·4시간 방향에 따른 새 차단 조건은 없다.

## 왜 알람이 나왔거나 없었는지

- 신호에 과매도/과매수 준비 시각·RSI, 첫 극점·첫 장악형 마감, 눌림 시작,
  두 번째 극점·두 번째 장악형 마감, 경과 봉 수를 함께 저장한다.
- 발송 문구에 두 반전의 시각, 두 번째 극점 가격, 목표의 근거를 추가했다.
- `video_alert_decisions`에 매 평가의 정책 버전, 입력 해시, 비용 가정, 전체 후보,
  대기/탈락 사유, 실제 조회 호가와 선택한 계획을 보관한다. 최초 판정은 덮어쓰지 않는다.
- `waiting_first_engulfing`, `waiting_pullback`, `waiting_second_engulfing`,
  `second_extreme_outside_band`, 만료와 비용 탈락을 구분한다. 기존 단순 무신호 집계보다
  어느 단계에서 멈췄는지 알 수 있다. 진단 기록은 발송 허가로 사용하지 않는다.
- 자료는 32일간 보관한다. SQLite 신규 테이블은 기존 발송 예약과 분리된 가산 변경이다.
  실제 후속 체결/수익 장부를 구현했다고 주장하지 않는다. 오프라인 재생에선 기존
  다음 봉 시가 모형과 봉내 목표·손절 선후불명 처리를 유지한다.

## 같은 과거 자료의 결과 — 개선을 입증하지 못함

이미 사용했던 파생 5분봉 581개, 6개 연속 구간, 평가 361봉을 비교했다.
기존 결과 파일의 입력 SHA256과 원자료 해시가 같은지 검사했다. 미사용 검증 표본이 아니다.

| 항목 | 기존 | 수정 |
| --- | ---: | ---: |
| RSI 후보 | 5 | 3 |
| CCI 돌파 후보 | 26 | 26 |
| 최종 진입 통과 | 0 | 0 |

같은 방향·같은 신호봉 기준 RSI 유지 2, 제거 3, 추가 1이다. CCI의 후보·계획·후속
결과는 완전히 동일하다. 동일 첫 극점 시각으로 묶은 롱 후보는 45분 빨라졌지만,
숏 후보는 앞선 신호가 제외되어 50분 늦어졌다. 이것은 후보 시각 비교이지 실제
체결 거래 매칭이나 전체적인 조기 포착 개선이 아니다.

**불리한 결과도 보존했다:** 10월 19일 19:55 KST에 추가된 롱 후보는 이후 60분
종가가 약 0.104% 하락했다. 제외된 20:40 후보는 이후 60분 약 0.455% 상승했다.
단순히 먼저 울렸다고 더 정확한 신호가 된 것은 아니다. 둘 다 비용 기준 미달로
실제 알람 통과 대상은 아니었다. 후보의 이후 가격 변화는 거래 손익이 아니다.

비교 파일에는 모든 추가·제외·유지 후보의 전후 계획, 이후 1/3/6/12봉 방향별 종가 변화,
최대 유리/불리 가격 변화, 연속 후속 봉 수를 넣었다. 자료 공백 뒤 수익을 계산하지 않는다.
최종 진입이 없어 적중률과 순익 개선은 `null`이다.

첨부 화면의 정확한 봉 원자료는 확보하지 못했으므로 그 화면에서 어느 시각 알람이
발생했을지 재현했다고 주장하지 않는다. 실제 스프레드·체결·펀딩도 이 자료에 없다.

## 검증과 재현

```sh
python -m unittest test_lbank_rsi_sequence test_lbank_video_entry \
  test_lbank_video_alert test_lbank_native_candles test_lbank_telegram_transport
python -m research.zerobase.compare_video_rsi \
  --output research/zerobase/video_rsi_sequence_comparison_20261104.json
git diff --check
```

관련 시험 51개 통과. 합성 롱/숏 두 반전 순서, 첫 반전 누락, 꼬리만 이탈,
V자 반등, 밴드 밖 두 번째 극점, 더 낮은 두 번째 저점, 만료, 미래 봉 제거 시 동일 판정,
중심선 돌파 후 실제 구조 목표, 무근거 3R 목표 금지, 영속 근거·중복 예약,
호가 재검사와 Telegram 대체 함수 호출 경로를 확인했다. 실제 메시지를 보내지 않았다.

기존 시험의 반등 fixture에는 첫 장악형이 없었다. 규칙을 다시 완화해 시험을 통과시키지
않고 그 fixture를 '첫 반전 누락 시 제외' 시험으로 보존했다. 별도의 두 장악형 합성 자료로
정상 경로를 검사했다. 과거 자료 예상 개수도 새 결과에 맞추되 전체 후보 비교를 보존했다.

운영 승격 전 남은 작업은 **해당 실제 연속 봉·호가 자료에서 거래별 결과 비교**다.
완료한 합성 시험이나 동일 개발 표본을 반복하는 것으로 이 근거를 대신하지 않는다.
현재 결과만으로 정확도가 향상됐다는 배포 판단을 내리지 않는다.
