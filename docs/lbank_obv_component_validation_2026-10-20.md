# 공개 OBV 전략 구성요소 검증 — 2026-10-20

## 원전과 재현 범위

Deprez·Frömmel(2024), [Are simple technical trading rules profitable in bitcoin markets?](https://biblio.ugent.be/publication/01HY3C3S169G1N6QNYR55NZMFB), [기관 공개 원문](https://biblio.ugent.be/publication/01HY3C3S169G1N6QNYR55NZMFB/file/01HY60XZGZYHNQ6188MSVJT0SG.pdf)의 B.1·B.6·B.7 및 3.4를 확인했다. 원문은 누적 거래량에 이동평균을 적용하고 이전 기간 성과로 다음 달의 규칙을 선택한다. 전체 연구는 Bitstamp 현물이며 다양한 규칙군·빈도와 통계 선별을 결합한다. 본 결과를 논문 전체의 재현 또는 LBank 선물의 검증된 성과로 부르지 않는다.

원전 기본 OBV는 종가가 전봉보다 높거나 같으면 해당 봉 거래량을 더하고, 낮으면 뺀다. 본 구성요소는 원전의 p<q 이동평균 55쌍, 10·30·60분 세 빈도에서 총 165개를 모두 계산한다. 밴드·추가 확인 지연이 0이고 반대 신호까지 보유하는 구성요소만 사용한다. 이 선택은 성과 확인 전 고정했다. 원문의 비율 밴드, 유한 보유기간의 추가 해석, 전체 다중검정/FDR는 재현하지 않았다. 확인한 원문·기관 소개 페이지에서 저자 실행 코드 링크를 확보하지는 못했다.

## 이번 구현의 차이와 한계

[고정 규약](../research/continuation/obv_component_protocol_20261020.json), [구현](../research/continuation/obv_component.py), [검사](../research/continuation/test_obv_component.py)를 보존한다.

- Binance USD-M의 기존 검증 원본 1분 시세·거래량과 공시 펀딩으로 이식한다. Bitstamp와 LBank의 성과로 동일시하지 않는다. 전 구간이 다른 후보 조사에서 이미 관찰된 역사적 자료이며 탐색 평가다.
- 완성 봉 후 1분의 공개 지연을 둔 다음 분 시가를 사용하는 1배 롱/현금 수익 모형이다. 현금 이자 0, 공시 펀딩의 불리한 납부만 반영한다. 실제 선물 주문 체결·증거금·청산 모형이 아니다.
- 이전 12개월 중 원본과 이력이 완전한 달이 9개 이상일 때 순로그수익으로 best1·best50을 선택하고, 해당 월에 고정한다. 동일 기간의 단순 보유 기준을 뺀 수익 순위는 절대 수익 순위와 같다. 규칙 순서로 동률을 해소한다. 비용 두 배에서 선택 규칙을 다시 고르지 않는다.
- 월초에 동일 초기 자금을 각 규칙에 배정하고 월중에는 재조정하지 않는다. 월 경계마다 현금으로 종료·재시작하며 비용을 부과한다. 원문 포트폴리오 재구성의 모든 실거래 세부를 동일하게 재현한 것은 아니다.
- 원본 공백과 불일치를 전 필드 기준으로 격리한다. 원본 완전성과 최대 지표 이력이 월 전체에 확보되지 않은 달은 통째로 검증 제외한다. 구멍에서 임의 청산해 이익을 확정하지 않는다. 제외된 달의 손익을 0이나 성공으로 처리하지 않는다. 따라서 결과는 완전한 연속 기간의 실행 가능 계좌 성과가 아니다.
- 원문 구성요소에는 현재 알람에 필요한 고정 손절·TP1·긴급 위험 후속 계약이 없다. 해당 평가를 통과했다고 표시하지 않는다. 연구 후보의 이점이 확인되어도 별도 위험·실행 검증 전 실전 승격할 수 없다.

## 실행 결과와 판정

원본 1분 2,496,960개에서 기존 감사의 불일치 160분을 격리했다. 165개 구성요소를 모두 실제 계산했다. 월별 원본·최대 지표 이력의 완전성 및 과거 12개월 중 9개 이상 완전한 학습 월 조건을 함께 적용하니 평가 대상은 **2024년 1~9월·12월과 2026년 2~8월, 총 17개월 517일**이었다. 2025년은 자료 완전성 또는 학습 월 부족으로 전부 제외됐다. 따라서 **아래 누적값은 연속된 2024~2026년 계좌 수익률이 아니다. 제외 월의 손익은 미상이다.** 연간 수익률이나 미래 기대수익으로 표시하지 않는다.

위 비교는 동일 월·비용·펀딩·월말 현금 종료를 적용한 모형이다. 원문 전체의 벤치마크, 실제 사용자의 보유나 선물 계좌가 아니다. 낙폭은 관측 일별 기준으로, 분중 낙폭이나 제외 월 손실을 알 수 없다. 신뢰구간은 실제 달력 공백을 넘지 않는 최대 7일 블록 2,000회 재표집으로 계산했다. 좋은 기간을 추후 발견한 실험에 그대로 재사용했으므로 이를 독립 검정이나 확정된 통계 우위로 부르지 않는다.

비용 두 배에서 2026년 부분 구간은 두 방식 모두 손실이었다. 전체 양수는 주로 2024년 관측 구간의 기여다. 순기대수익 불확실성 하한도 양수를 확인하지 못했다. **수익성 있는 대체 알람으로 채택하거나 배포하지 않는다.** 이 결과로 모든 OBV 전략 또는 논문 전체가 무효라고 일반화하지 않는다.

1개 선택 모형의 종료 거래는 73건, 승률 41.1%, 평균 보유 약 80.2시간이다. 50개 모형의 장부에는 5,174개의 겹치는 규칙별 거래가 있고 승률은 38.8%지만, 이를 독립 알람 5,174건으로 세지 않는다. 원전 기본형에 손절·TP1이 없으므로 해당 적중률, 5분 내 긴급 경고율, 초기 위험 R 및 현재 운영 손실 한도 적합성을 검증했다고 말할 수 없다.

## 재현 및 감사

[전체 결과](../research/continuation/results/obv_component_20261020_report.json), [월별 실제 선택 규칙](../research/continuation/results/obv_component_20261020_monthly_choices.json), [요약](../research/continuation/results/obv_component_20261020_summary.json)을 보존했다. 분리된 거래·일별 평가 장부는 증거 묶음의 `ledgers/obv_component_final/`에 있다. 각 파일 SHA256은 전체 결과에 기록했다.

8개 구현 검사가 통과했다. 실자료에서 규칙별 거래 합계·일별 수익·모형 전체의 이익/손실 합계가 서로 일치함을 추가 확인했다. 단순 보유 비교, 달력 공백을 보존하는 재표집, 실제 학습 월 수의 표시를 추가한 [구현 감사 기록](../research/continuation/obv_component_implementation_notes_20261020.json)을 남겼다. 최종 진단 정보 수정 전후의 선택 규칙·거래 장부·일별 수익·성과 수치가 동일한 것을 해시와 값으로 대조했다. 초기 미완성 진단 결과도 `initial_diagnostics_superseded` 이름으로 보존하며 최종 근거와 구별한다. 구현 검사 통과는 수익성 통과가 아니다.

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m unittest research.continuation.test_obv_component
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m research.continuation.obv_component --output <output-directory>
```

다음 단계는 원본 체결 자료 등 독립적인 공식 자료로 불일치 원인을 확인해 전체 달력 검증이 가능한지 조사하는 것이다. 성과를 좋게 만들려고 9개월 학습 조건을 낮추거나 제외 월을 성공으로 바꾸지 않는다. 자료 버전을 달리 검증할 때는 규칙을 고정하고 버전별 결과를 함께 보고해야 한다. 그 경로를 복구할 수 없으면 미해결 이유를 기록하고 다음 공개 후보로 이동한다.

다음 후보인 Bouri 외(2021)의 하루 전 곡선 예측 전략은 [Essex 기관 공개 원문](https://repository.essex.ac.uk/30487/)을 확보했다. [출처·재현 준비 기록](../research/continuation/functional_curve_source_audit_20261020.json)을 남겼지만 해당 모델 계산이나 성과 재현은 아직 수행하지 않았다. 이 논문의 로그수익 기반 낙폭 표기를 일반 계좌의 퍼센트 낙폭과 혼동하지 않는다.

현재 운영 소스와 알람 정책은 이번 연구로 교체하지 않았으며, 전향 검증을 시작한 합격 대체 후보도 아직 없다.
