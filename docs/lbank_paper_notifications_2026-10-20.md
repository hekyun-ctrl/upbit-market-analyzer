# LBank 검증용 모의 알림 v1 — 2026-10-20

사용자는 기존 연구의 자동 후속 진행과 자주 발생하는 검증용 모의 알림을 승인했다. 기존 공개기법4종/RSI 다이버전스 연구의 SQLite 기록을 읽는 별도 daemon 발신기를 연결했다. 기존 후보·진입·청산 규칙과 실전 쿨다운·일일 상한·증거금·손실·위험 경고는 변경하지 않는다. 최신 운영 기준862339d에 적용한 관측/알림 기능이며 수익성 있는 대체 전략 승격이 아니다.

## 발신 동작

- 모든 메시지에 [검증용 모의 알람 · 실전 진입 금지], 실제 주문 없음, 가상 체결/비용 모형이라는 표기.
- 서로 다른 새 후보/모의 진입/TP1 상태/종료를 최대4사건씩, 최대1분당1메시지로 묶는다. 동일 사건 반복으로 표본을 늘리지 않는다. 실제 발생 빈도를 보장하지 않으며 후보가 없으면 진입을 만들어내지 않는다.
- 15분 달력 구간마다 짧은 가격 기록 상태를 알린다. 상태 보고·후보 수는 거래 수나 종료 성과로 세지 않는다.
- 연구 DB는 read-only로 열고 별도 /data/lbank_paper_notifications.sqlite3에 발신 상태만 보존한다. 모의 메시지는 별도 스레드/전송 인스턴스에서 보내므로 네트워크 대기가 실전 위험 처리 루프를 점유하지 않는다.
- 전송 시도 전에 사건을 예약한다. Telegram 실패/불명확 응답 또는 예약 직후 프로세스 중단은 재전송하지 않고 기록에 남긴다. 따라서 중복은 줄이지만 알림 누락 가능성은 있다. 원래 모의 장부는 삭제/변경하지 않는다.
- 초기 시작 이전 후보/진입은 새 알람으로 재발신하지 않는다. 5분 넘은 미발신 사건은 stale_not_sent로 보존한다. 로컬 발신 기록은7일 보존하며 원래 연구 장부 보존은 기존 정책을 따른다.
- 기존 장부는 TP1 최초 시각을 별도 저장하지 않는다. 해당 알림은 '상태 확인 시각/최초 도달시각 미기록'을 표시하며 임의 시간을 만들지 않는다. 목표 후 수익 모형의 부분 익절50%는 기존 모형이다.
- 가격/봉/연구 기록 미준비와 자료 공백 검열 결과를 수익으로 표시하지 않는다. 분봉 사이 체결·실제 슬립/펀딩·5분 내 실제 긴급 경고율·수동 체결 가능성이 이 알림 패치로 검증되는 것은 아니다.
