## 사용자의 정정과 변경 범위
12:38 배포한 ‘후보 이후 완료 1분봉 2개 필수 대기’는 사용자 의도와 달랐다. 작은 확인 조건을 전역 AND로 추가해 신호를 늦추거나 줄이는 대신 더 큰 근거가 유지되는지를 우선 판단하도록 변경했다. 이 문서는 같은 날의 최초 필수 대기 방식을 대체한다. 모든 봉을 기다리지 않거나 알람 건수·수익이 늘어난다고 보장하는 변경은 아니다.

## 우선순위
1. **최상위 제약:** 원래 손절선·후보 손절 근거, 데이터 신뢰성, 과도한 가격 이탈/추격, 비용·위험 예산. 상위 추세라는 이유로 이를 완화하지 않는다.
2. **상위 방향·구조:** 완료된 5분봉 최근 3개의 고점과 저점이 모두 제안 방향으로 전진하는지, 15분봉 최근 2개 종가 변화가 같은 방향인지, 5분 EMA9/21의 배열과 EMA9 기울기가 같은 방향인지 판단한다. 현재가가 최근 3개 5분봉의 보호 저점/고점 안쪽인지도 본다.
3. **목표 공간:** 과거 확인된 5분봉 국소 고점/저점(좌우 2봉 확인)을 앞쪽 장벽으로 검토한다. 목표와 충돌하는 장벽이 확인되면 ‘상위 근거 우세’로 분류하지 않는다. 장벽이 없으면 여유가 충분하다고 만들지 않고 unknown으로 기록한다.
4. **짧은 반응:** 후보 대비 현재 가격의 작은 후퇴와 추가 1분봉 몸통·종가 반응은 보조 증거다. 두 완료봉이 없거나 반응이 덜 강하다는 이유만으로 새 대기시간을 강제하지 않는다.

임의의 ‘성공 확률 90%’나 최적화되지 않은 숫자 가중치를 표시하지 않는다. 위 계층은 공개된 재현 가능한 운영 가설이며 수익으로 검증된 점수가 아니다. 여러 가격 지표는 서로 독립된 정보가 아닐 수 있다.

기존 30~240초 재확인, ±0.10% 가격 이탈 제한, RSI 방향, 상위 맥락, 비용 후 손익비와 위험/증거금 한도는 유지한다. 새 2분·3분 필수 대기는 제거한다. 상위 근거가 우세하면 약한 단기 MACD/반응 확인이나 추세 재확인의 짧은 모멘텀 약화가 단독으로 후보를 막지 못한다. 실제 돌파선 복귀나 후보 손절 침범은 우선 차단한다.

상위 근거가 우세하지 않으면 이전의 원래 진입 심사를 적용하며, 큰 근거가 있다는 추측으로 심사를 통과시키지 않는다. 전체 알람 수가 유지되거나 증가한다고 단정할 수는 없다. 기존 손절·데이터·비용 등의 실제 제약은 여전히 알람을 막는다.

## 발송 후 단기 역행과 완전 무효화 구분
새 정책으로 생성한 신호에서 기존 조기경고 조건(원래 손절 거리의 55% 이상 역행, 최근 표본 대비 0.08% 반대 움직임, 2회 연속 위험 점검)이 발생하면 같은 시점의 신선한 원본 자료로 상위 근거를 다시 평가한다.

- **상위 구조 유지:** ‘단기 역행 주의’ 알림을 한 번 보내고 기존 신호를 계속 추적한다. 이것은 새로운 진입 추천이나 위험이 없다는 뜻이 아니다. 가격과 원래 손절을 함께 표시한다.
- **상위 근거 약화·충돌 또는 자료 미확인:** 기존 긴급 무효화 경고로 처리한다. 먼저 주의를 보낸 신호도 이 상태로 바뀌면 긴급경고를 보낸다.
- **원래 손절선 도달:** 상위 근거보다 항상 우선하는 긴급경고다. 손절을 넓히거나 삭제하지 않는다.

발송 시 정책 버전을 고정하며 이미 발송된 구버전 신호의 정책을 소급 변경하지 않는다. 기존 수동 신고 포지션의 위험 관리도 변경하지 않는다. 상위 근거 유지는 최근 완료된 봉의 판단이며 다음 틱이나 돌발 사건까지 보장하지 않는다.

단기 주의 메시지를 보냈다고 경고 청산 모형을 종료하지 않는다. 주의 이벤트는 독립 표에 저장하고, 실제 완전 무효화가 전달됐을 때에만 기존 warning_exit 모형을 종료한다. 주의 전송 실패는 재시도하며 성공 확인 전에는 통지 완료로 처리하지 않는다. 재시작해도 정책 버전·주의 전송 여부·상위 근거를 복구한다. Telegram 전달과 장부 기록의 완전 원자성은 기존과 마찬가지로 보장되지 않는다.
