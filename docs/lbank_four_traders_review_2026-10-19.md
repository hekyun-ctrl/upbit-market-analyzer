# 네 트레이더 기법 검토와 LBank 알람 적용 — 2026-10-19 KST

**결론:** 포지션의 기준시드 대비 노출과 손절 손실률을 실제 알람에 추가한다. 3단 하락 반등, 더블비 1시간봉, 더블비 5분봉 변형, 박스 돌파 후 재지지는 네 개의 독립 모의검증으로 연결한다. 기존 진입 조건에 필수 확인 항목을 더하지 않으며, 새 기법을 실제 진입 신호로 자동 승격하지 않는다. 수익성이나 알람 증가가 검증됐다는 의미는 아니다.

## 원본과 구현의 차이

모든 실험은 현재 LBank BTCUSDT 원본 1분봉에서 집계한 완료 5분봉만 사용한다. 가격 표본으로 OHLC를 만들거나, 결측 봉을 채우거나, 현재 형성 중인 봉을 완료 봉으로 취급하지 않는다. 현재 완료 판정은 거래소 스트림 시각을 통한 추론이며 REST로 재검증된 과거 봉이라는 뜻은 아니다.

* **3단 하락 반등:** 최근 10개 봉에서 의미 있는 하락 종가 단계를 센다. 단계 최소 폭은 직전 20개 진폭 중앙값의 0.5배와 가격의 0.01% 중 큰 값이다. 비슷한 종가는 합치고 의미 있는 회복은 단계를 초기화한다. 세 번째 하락 완료 뒤 별도 1분봉 반응을 기다린다. 이 수치와 완료봉 진입은 재현 가능한 연구용 정의이며 나씨의 완전한 원본 규칙이 아니다. 원본의 장중 선진입과 물타기를 제거했다.
* **더블비:** BB20에는 종가·표준편차 2배, BB4에는 시가·표준편차 4배를 사용한다. 20이평 상승 중 두 하단 동시 접촉은 롱 후보, 하락 중 두 상단 동시 접촉은 숏 후보다. 역추세 접촉만으로 반전을 선언하지 않는다. 원형 1시간봉은 연속된 5분봉 12개로 만들며, 완료된 22시간이 있어야 계산한다. 5분봉 버전은 원형과 다른 실험이다. 원본 영상만으로 확정되지 않은 진입 완료 시점과 손절은 기존 시스템 규칙으로 명시했다.
* **박스 재지지:** 돌파봉과 재시험봉보다 앞선 20개 봉으로 박스 경계를 고정한다. 0.2 ATR를 넘는 돌파 뒤 다음 봉이 경계를 재시험하고 다시 바깥에서 마감하며, 20이평 방향이 맞아야 한다. 손절 근거는 재시험 저점/고점이다. 뒤에 나타난 고가·저가로 과거 박스를 바꾸지 않는다. 이 기간·허용 폭은 자체 검증용 정의다.

후보는 15분 이내에만 유효하다. 구조 손절 근거를 먼저 이탈하면 무효다. 후보가 생긴 뒤 시작한 완료 1분봉이 최근 3분 고점/저점을 돌파하는 반응, 현재가 이탈 제한, 기존 방향성 RSI·시장 맥락·비용·손절·목표 도달 가능성 심사를 거친다. 최초 확인 후 30~240초에 다시 확인한 경우만 모의 진입한다. 각 실험은 동시에 한 개의 분할목표 모형 포지션만 보유한다. 서로 다른 실험끼리는 중복될 수 있으므로 손익을 합쳐 계좌 수익이라고 부르지 않는다.

모의기록에는 진입 당시 규칙·가격·판정 이유·비용·원본 봉 출처를 고정한다. 재시작 후 같은 후보가 다시 진입하지 않으며, 관측 공백이 있는 결과는 승패에 넣지 않는다. 일일 기존 보고에 네 실험의 진입·완료·공백·평균 모형 순손익을 추가한다. 최대 90일 보관 범위이며, 실제 주문이나 실체결 수익이 아니다. 완료봉 조건과 모의 수익 계산은 서로 다르다. 이후 손익은 기존 가격 관측 모형을 사용하므로 봉 내부의 모든 손절·목표 접촉이나 호가 체결을 재현하지 못한다.

## 실제 알람의 변경

표시 예: `레버리지 30배 | 기준시드 노출 1.50배`, `예상 총손실 … USDT (기준시드 0.50%)`.

노출 배수는 `포지션 명목금액 / 시스템 기준시드`다. 예를 들어 기준시드의 5%를 증거금으로 사용하는 30배 포지션은 기준시드 대비 1.5배 노출이다. 증거금 최대 15%와 30배는 노출 상한으로 4.5배에 해당하지만 실제 제시 수량은 기존 손절 위험 한도에 의해 더 작아질 수 있다. 손절 예상 손실은 기존 수수료·슬리피지·펀딩 비용 모형을 포함한다. 급변 시 실제 손실 상한을 보장하지 않는다.

시스템 기준시드는 사용자가 앞서 제공한 참조값이며 거래소에서 검증한 현재 총자산이 아니다. 거래소 레버리지, 최대 증거금 비중, 1회 초기 손절 위험 0.5%, 기존 진입 순서와 재확인·쿨다운은 이번에 바꾸지 않았다. 이미 승인된 알람과 같은 방향의 실험 패턴이 동시에 존재하면 참고 이름만 붙인다. 이 표시가 신호의 검증된 성공 확률을 뜻하지 않는다.

추가 실험은 기존 알람의 모든 심사 뒤에서만 설명을 붙이고, 별도 장부로 관찰한다. 새 지표를 AND 조건으로 추가해 기존 알람을 줄이는 구조가 아니다. 새 후보로 실제 진입 알람을 추가하는 단계도 아직 아니다.

**이 숫자는 매매 횟수·승수·수익 기회 수가 아니다.** 해당 구간의 전체 원본 1분봉과 후속 시세가 없으므로 진입 반응·재확인·손절·체결을 소급 재현하지 않았다. 표본도 짧고 한 시장에 한정된다. 미래 성과나 실제 알람 증가를 입증하지 않는다. 재실행: `python research/audit_public_techniques.py`.

워뇨띠 공개 ZIP의 SHA256은 `b6f1dc7aadf8209bf6c99fd516a06c0cabdc77c5f16f9fc8df92fdf1d8d01b9a`다. 2018~2021년 실행 기록 **1,444,583행** 중 거래 체결은 1,439,207행, 펀딩 5,368행, 정산 8행이었다. 거래 주문 ID는 23,417개다. 여러 체결이 같은 주문·포지션에 속할 수 있으므로 어느 숫자도 독립된 완결 매매 횟수가 아니다.

XBTUSD 체결 명목금액으로 가중한 maker 비중은 2018년 64.56%, 2019년 67.91%, 2020년 70.41%, 2021년 77.08%였다. 이는 거래 비용과 실행 방식이 결과에 중요하다는 자료상의 관찰이다. LBank에서 같은 체결 우위를 얻을 수 있다는 증거는 아니므로 현재 taker 비용 가정을 낮추지 않았다. 계산은 공식 BitMEX의 역선물 계약 구분과 실행 기록 종류를 참고했다.

실행 ID 중복은 없었지만 원본 행 순서에서 시간 역전 4,319건이 있었다. 지갑 자료는 빈 행 2,135개를 제외했고, 취소된 출금 7건도 현금흐름에서 제외했다. 완료된 2,246건의 시작·끝 잔액과 금액 합계 잔차는 **0 satoshi**였다. 그러나 일부 숫자에 과학적 표기, 잘린 시각과 날짜 역전이 있어 일중 자산·실효 배율·매매별 승률을 복원하지 않았다. 잔액 합계 일치는 자료의 독립적 진위 인증이나 계좌 소유 인증이 아니다. 원본 체결 ID의 거래소 대조도 수행하지 않았다.

공개자료에서 완전한 진입 공식을 찾았다고 주장하지 않는다. 캔들 위치와 상대 거래량은 일반적인 관찰값으로만 저장하며 ‘워뇨띠 공식’이라고 이름 붙이지 않았다. 공개 ZIP과 전체 영상 자막은 저장소에 재배포하지 않는다. 집계와 재현 코드만 포함한다.

## 후속 검증 기준과 운영상 제약

실험별 최소 30일·완료 모의 진입 100건을 초기 검토 기준으로 삼되, 이 기준만 넘었다고 자동 채택하지 않는다. 상승·하락·횡보 구간, 비용 차감 기대값, 손실 연속 구간과 낙폭, 중복 노출, 표본 밖 기간을 나눠 평가해야 한다. 승률만 높고 평균 손실이 큰 방식은 채택 근거가 약하다. 수수료와 슬리피지를 높인 경우도 비교한다. 실체결 검증이 없는 모형 손익을 일일 순수익 7% 달성으로 보고하지 않는다.

알람 빈도는 원시 패턴 수와 최종 비용·위험 심사 통과 수를 구분한다. 단순히 횟수를 늘리기 위해 구조 손절이나 비용 심사를 없애지 않는다. 별도 실험의 실전 전환은 이번 변경에 포함되지 않으며 자동으로 이루어지지 않는다.

배포 시 기존 원본 봉 수집기가 재시작된다. 현재 구조는 재시작으로 생긴 분봉 공백을 외삽하지 않으므로, 신규 진입 심사가 연속 5분봉 20개를 다시 확보할 때까지 약 100~105분 대기할 수 있다. 이 동안 알람 부재를 횡보라고 단정하면 안 된다. 1시간봉 실험은 연속 22시간 이상의 자료가 필요하며, 5분봉 실험과 별도로 준비 상태를 기록한다. 배포 완료와 모든 기법의 데이터 준비 완료는 서로 다른 상태다.

변경 전 250개 봉을 사용하던 실제 RSI 계산은 그대로 유지했다. 1시간 모의검증만 최대 300개 5분봉을 별도로 읽는다. 새 모듈 오류는 기존 알람 경로를 차단하지 않도록 격리했다. 로컬 검증은 기존 기능과 새 회귀 검사를 포함한 **252개 테스트**로 구성된다. 검증 항목에는 시가/종가 밴드 구분, 미래 봉 사용 방지, 결측·미완료 봉 차단, 1시간 집계, 기존 RSI 동일성, 재시작 중복 방지, 취소 출금 제외, 표시 노출·손실률이 포함된다.
