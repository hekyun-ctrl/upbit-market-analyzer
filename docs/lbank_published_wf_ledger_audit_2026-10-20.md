# 공개 WF 원전: BTC 장부의 비용·빈도 검산

2026-10-20 KST. 공개 논문의 BTC 두 모형에서 **같은 포지션 경로에 모형 비용을 두 배로 적용해도 과거 합계가 양수**인 결과를 확인했다. 다만 하루 진입 기회·관측일 비율·불확실성과 알람 계약이 고정 기준을 충족하지 않아 실전 교체하지 않는다. 이 결과는 LBank 실제 체결 수익이나 새로운 전략 개발 완료가 아니다.

## 원전·규약·실행

원전은 Mroziewicz·Ślepaczuk의 [2026년 논문](https://arxiv.org/html/2602.10785v1)이다. [분석 저장소](https://github.com/tmr-crypto/wf_optim_crypto_analysis/tree/a9b4d8d09da162c970253c0b8cb5e5b3f2400444)와 [거래 생성 저장소](https://github.com/tmr-crypto/wf_optim_crypto/tree/8be3ecf0019e991962f6f59bf9938cfa56411350)를 고정하고 관련 R 코드의 선택·비용 계산을 읽었다. 원전은 완료된 EMA 비교를 한 시간 지연해 사용하고, 과거 학습 창에서 선택한 EMA를 다음 평가 창에 적용한다. 이번에는 저자가 선정한 7일/28일, 14일/10일 BTC 경로를 모두 고정했다.

[검사 규약](../research/continuation/wf_double_source_audit_protocol_20261020.json)은 `2026-10-19T22:47:17Z`에 고정했다. 규약·코드·8개 검사는 성과 계산 전에 연구 커밋 `a6b05c283f8399222d9f866ee75d158ca10e28ef`에 저장했다. 규약 SHA256은 `772995d6d7fc59b407c4786203f69f2b8f6f04025e43b4fef174063a7280fd53`, [실행 코드](../research/continuation/audit_wf_double_source.py)는 `1e4f2e8b9c4ce6b8fef9d9274451a90444d0ba50b91caf08cc6f18ad9a4e21d4`다.

실제 계산은 `2026-10-19T22:50:54.707078Z`~`22:50:55.597263Z`에 실행했다. Python 3.12.14, numpy 2.3.5, pandas 2.2.3, rdata 1.0.0을 사용했다. R 실행 환경은 없었고, R/DVC·외부 매매 코드는 실행하지 않았다. RDS 숫자 자료를 읽어 공개 장부를 별도 Python 코드로 검산했다. 전체 EMA 탐색과 논문의 모든 분석을 재현한 것이 아니다.

## 자료와 정합성

[저자 공개 ZIP](https://drive.google.com/file/d/1y7J3cGFEYYBufVTACzPYr4GXiUSCOKm7/view)을 실제 내려받았다. 80,263,893바이트, SHA256 `2bb40a7860733ba073a089c82b3424f4551d101d061fb31f4e9f51da978a81fd`. 원본 거래소의 공시 SHA가 아니라 이번에 고정한 저자 배포물의 해시다. [92개 파일 목록·크기·해시](../research/continuation/results/wf_double_source_20261020/zip_members.json)와 사용한 BTC 원본 RDS 두 개·선택 창 RDS·시각 범위 YAML을 함께 보존했다.

저자의 가공된 Kaggle 가격·포지션 자료다. 전처리 코드에는 가격 결측의 앞값/뒷값 채움이 있다. 최초 거래소 원본·모든 보간 행을 대조하지 않았으며, LBank 원본 OHLC·호가가 아니다. 2019~2021년이라는 연도만으로 독립 미관측 검증이라 부르지 않는다. 이미 결과가 발표된 원전의 탐색적 역사 자료이고, 규칙 고정 후 새로 발생한 전향 표본은 0이다.

전체 배포 경로는 각각 16,800행/16,560행이다. 중복은 없고 가격·포지션·수익 자료의 유한성, 양의 가격, 포지션 ±1과 가격 로그수익 일치를 확인했다. 두 경로의 전체 구간에는 동일한 `2019-10-23 10:58 UTC` 비정시 표본으로 인한 59분·61분 간격이 있다. 이를 누락 시간이나 조작으로 단정하지 않고 비교 불명확한 두 경계를 제외했다. 보간·공백 청산은 하지 않았다. 전체 구간 합계는 해당 경계를 제외한 진단이며 완전한 계좌 수익률이 아니다.

논문에서 미리 정한 공통 구간 `2019-11-07 00:59 UTC`~`2021-08-22 23:59 UTC`는 두 모형 모두 15,720행·655일, 비정시 간격 0이다. 좋은 기간을 사후 선택하지 않도록 전체 배포 구간도 함께 계산했다. 학습 종료가 평가 시작보다 앞서는 선택 창을 확인했지만 저자의 모든 학습 통계·원본 결측을 재구축하지는 않았다.

## 실제 비용 대조와 결과

저자 비용은 거래대금 기준 한쪽당 0.1%를 차감하는 로그수익 모형이다. 선택된 EMA가 바뀌는 평가 창 경계에서는, 개별 EMA 경로에서 미리 계산한 비용과 실제 선택된 포지션 전환 비용이 달라질 수 있다. 실제 장부에서 7/28 모형은 **전환 4건·편도 수수료 8회분**, 14/10 모형은 **전환 7건·편도 수수료 14회분**의 비용 누락을 확인했다. 모두 평가 창 경계였다. 동일한 선택 포지션에 그 비용을 반영하고 0.2%로도 계산했다. 새 파라미터를 고르거나 매매 신호를 바꾸지 않았다.

다음은 공통 655일 구간의 **로그수익을 지수화한 진단값**이다. 정확한 선물 계좌 재현·펀딩을 포함한 실제 순수익으로 해석하지 않는다.

| 항목 | 학습 7일 / 평가 28일 | 학습 14일 / 평가 10일 |
|---|---:|---:|
| 모형 비용 보정 후 누적 진단값 | +237.74% | +404.88% |
| 동일 신호·모형 비용 두 배 | +89.86% | +180.43% |
| 기본 비용 자산 경로의 최대 낙폭 | 53.96% | 49.79% |
| 일평균 실제 포지션 전환 | 0.440 | 0.449 |
| 포지션 전환이 있는 날 | 211/655, 32.21% | 210/655, 32.06% |
| 확인 가능한 종료 구간 | 287 | 293 |
| 동일 진입 거래대금 기준 종료 구간 PF | 1.354 | 1.469 |
| 일 단위 기대 로그수익 95% 하한 | -0.1042% | -0.0661% |

하한은 7일 이동 블록·2,000회·seed `20261020`으로 일 단위 상관을 고려해 산출했다. 초기 위험 R의 기대수익 하한이 아니며, 독립 전향 기준을 통과한 값도 아니다. PF 역시 펀딩·실제 미끄러짐을 포함하지 않은 진단이다. 두 모형은 같은 가격과 비슷한 방향 경로를 사용하므로 종료 구간을 합쳐 독립 거래 수로 세지 않는다.

전체 배포 경로에서도 기본·두 배 모형 비용 합계는 양수였다. 비용 보정 후 지수화 진단값은 각각 +144.59%/+341.95%, 두 배 비용은 +35.31%/+137.74%다. 그러나 최대 낙폭은 63.44%/49.79%, 신뢰 하한은 두 모형 모두 음수였다. 일부 좋은 공통 구간만 제시해 채택하지 않았다. 상세 수치·비용 누락 시각·원본 해시는 [계산 결과](../research/continuation/results/wf_double_source_20261020/report.json)에 있다.

최초 보유 포지션은 진입 경위를 모르므로 새 알람으로 세지 않았다. 마지막 미청산도 강제 종료하지 않았다. 종료 구간은 확인 가능한 포지션 전환 사이만 연결했다. 별도 고정 진입 거래대금 검산식은 `방향×(청산가/진입가−1)−수수료×(1+청산가/진입가)`이며, 원전의 연속 로그수익 모형과 구분했다.

## 검산·재현·한계

8개 검사는 상속 포지션, 누락/과다 수수료, 양방향 거래 비용, 공백 연결 금지, 종료 구간 가격과 최초 자산 대비 낙폭을 확인했다. [별도 검산 코드](../research/continuation/verify_wf_double_outputs.py)는 원본 RDS의 수익에서 비용 차이만 더하고 빼는 다른 산술 경로로 합계·전환 건수·종료 거래의 이익/손실 합계를 다시 대조했다. [검산 결과](../research/continuation/results/wf_double_source_20261020/independent_audit.json)는 통과했다. 같은 연구자의 별도 계산이며 외부 기관 검증은 아니다.

저자가 가정한 0.1%는 수수료·스프레드·미끄러짐의 모형값이다. 실제 펀딩·수동 주문 지연·체결 가격을 관측한 것이 아니므로 두 배 검사를 native 비용 스트레스 통과로 부르지 않는다. 공매도의 로그수익 부호 전환도 실제 포지션 장부와 같다고 보장하지 않는다. 원전에는 고정 손절·TP1·경고 계약이 없어서 초기 R, TP1 선도달, 5분 내 역행/긴급 후속을 계산할 수 없다. 시간별 종가로 이를 추정하거나 경고를 0건으로 넣지 않았다. 낙폭 %를 10R 기준으로 변환하지 않았다.

코드와 원본 파일의 복구 없이 기존 Git 결과만 검사하려면 rdata 1.0.0, xarray 2025.1.2와 기록한 numpy/pandas/PyYAML 환경을 준비하고 다음을 실행한다. 의존성은 별도 임시 경로에만 설치했으며 운영 환경을 변경하지 않았다.

```bash
PYTHONPATH=/tmp/lbank-rdata-1.0.0 python -m unittest discover \
  -s research/continuation -p test_wf_double_source_audit.py -v

PYTHONPATH=/tmp/lbank-rdata-1.0.0 python research/continuation/verify_wf_double_outputs.py \
  research/continuation/results/wf_double_source_20261020

PYTHONPATH=/tmp/lbank-rdata-1.0.0 python research/continuation/audit_wf_double_source.py \
  --archive /tmp/lbank-wf-published.zip --download \
  --output /tmp/lbank-wf-published-replay
```

이번 실행은 이미 내려받은 ZIP을 사용했다. 마지막 명령의 새 환경 전체 복구는 별도로 실행하지 않았다. `--download`는 누락 때만 저자 URL을 읽고 고정 SHA 불일치면 중단한다. 실제 실행·설치 명령과 배포물 해시는 [기록](../research/continuation/results/wf_double_source_20261020/delivery.json)에 있다. 원본 선택 RDS를 Git에 보존해 임시 파일이나 저자 ZIP의 영구 유지에만 의존하지 않는다.

## 판정·다음 단계

과거 비용 모형에서 양수인 기존 원전이 있다는 구체적 증거는 확보했다. **이 두 모형을 실전 수동 알람으로 교체할 근거는 부족하다.** 빈도 1건/일 및 절반 이상 관측일 기준에 미달하고, 기대수익 하한도 양수가 아니다. TP1·경고·native 체결·최소 30일/100건의 새 전향 검증은 미충족이다. 단순 빈도 증가나 손절 추가로 원전과 다른 규칙을 만들어 통과시키지 않는다. 이 결론은 모든 EMA나 모든 대체 전략의 부정이 아니다.

사회 신호 원전의 [접근·적합성 검사](../research/continuation/social_signal_source_screen_20261020.json)도 마쳤다. 광고된 자료/코드 URL은 이번 접근에서 404였고 일 단위 모형의 장중 보호 계약을 확보하지 못해, 수익률을 임의 재현하지 않았다.

다음 실행은 [고정한 native 호가 기초 관측](../research/continuation/native_quote_baseline_protocol_20261020.json)으로 실제 입력·왕복 지연·스프레드·자료 누락을 기록한다. 기존 검토된 읽기 전용 호가 함수만 이용하며 새 전략이나 방향 알람은 발신하지 않는다. 이는 특정 후보의 전향 검증 시작이 아니다. 그다음에도 공개 코드·자료·비용 후 근거와 적절한 빈도를 갖춘 다른 원전 검색을 이어간다. 운영 변경·재시작·Railway 배포는 수행하지 않았다.
