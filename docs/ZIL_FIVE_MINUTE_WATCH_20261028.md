# 질리카 알람: 5분 단위와 고점 대비 가격 설명

2026-10-28 우주심 요청에 따라 질리카 전용 거래량 알람을 수정한다.

- 1분봉 알람과 1분 조회를 제거한다. 완료된 5분봉만 5분 경계 +3초에 조회한다. 프로세스 시작 직후에는 한 번 확인한다.
- 기존 5분봉 기준을 유지한다: 직전 20개 완료 5분봉 거래량 중앙값의 3배 이상이며 해당 봉 거래대금 3,000만원 이상일 때만 알린다. 추가 1.5배 조건을 복원하지 않는다.
- 매 5분 정시 무조건 발송하는 정기 보고가 아니다. 조건 충족 시에만 한 봉당 한 번 발송한다. 발송 확인 후 영속 중복 장부를 갱신하고, 오래된 과거 알람을 재생하지 않는다.
- 알람의 가격 설명은 발생봉을 포함한 최근 20개 완료 5분봉의 최고가와 그 봉의 시작 시각을 명시한다. 관측 구간 고점이며 당일 전체 고점이나 실시간 모든 체결의 고점으로 확대 해석하지 않는다. 진행봉·미래봉과 이 20개 범위 밖의 봉을 고점 계산에 넣지 않는다. 거래가 없는 구간에는 20개 봉이 실제 100분보다 길 수 있다.
- 현재가의 고점 대비 변동률, 급증봉 시가 대비 종가 변동률, 현재가의 급증봉 종가 대비 변동률을 표시한다. 현재가가 관측 고점 아래면 “고점에서 되밀린 가격”이며 거래량 급증이 상승 지속을 뜻하지 않는다는 설명을 붙인다. 급증봉이 양봉이어도 이 설명을 생략하지 않는다. 고점과 같거나 위에 있으면 되밀렸다고 표시하지 않는다.
- 이는 가격 관측 설명이다. 별도의 상승 동반·하락 동반 알람이나 새 하락 알람을 재개하지 않는다. 감지 조건과 현재가 조회의 신선도 제한, 기존 종료 시각, Telegram 발송 경로는 유지한다.

정책: `five-minute-volume-peak-context-v4`. 실행 상태 `config.zil_watch`에서 interval_seconds=300, thresholds의 5분 항목만 존재, peak_context=true, direction_alerts=false를 확인한다. 시작·주기 로그에는 interval=300 및 latest_5m이 기록된다.

## 검증

전용 시험 18개 통과: 거래량/거래대금 경계, 1분봉 제외, 5분봉만 요청, 5분 경계 스케줄, 영속 중복 억제와 실패 재시도, 미완성·미래·오래된 봉 제외, 낮은 거래량 무발송, 양봉 급등 후 고점 하회 설명, 고점 이상 오표시 방지, 최근 20개 완료봉 고점 범위 검사를 포함한다. Telegram은 모킹한다. 동작 검증이며 투자 성과 검증이 아니다.

중지 중인 질리카 외 업비트 알림의 환경 설정과 LBank/ZB 운영·연구 브랜치·모의 알림·주문은 변경하지 않는다. 배포 성공 여부는 Railway의 해당 실행 버전 SUCCESS 및 실제 300초 정책 조회 후에 별도로 보고한다.
