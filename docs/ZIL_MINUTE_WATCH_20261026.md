# 질리카 거래량 감시 — 기존 거래량 기준 복구, 방향 알림 중지

2026-10-26 최신 정정: 거래량의 추가 1.5배 조건은 취소하고 원래대로 복구한다. 상승 동반·하락 동반 알림 중지는 유지한다.

## 현재 발송 기준

- 완료 1분봉: 해당 봉 직전 20개 완료봉 거래량 중앙값의 **5배 이상**, 해당 봉 원화 거래대금 **1,000만원 이상**.
- 또는 완료 5분봉: 해당 봉 직전 20개 완료봉 거래량 중앙값의 **3배 이상**, 해당 봉 원화 거래대금 **3,000만원 이상**.
- 이는 PR #24에서 운영하던 원래 거래량 기준이다. PR #25의 마지막 발송봉 대비 고정 1.5배 비교는 제거했다. `ZIL_WATCH_REFERENCE_*` 변수는 코드에서 읽지 않으며 기존 수량 기준 JSON은 현재 브랜치에서 제거했다. 이전 변경 기록은 Git 이력에 남는다.
- `상승 동반`·`하락 동반`·방향 분류·지지 붕괴·시간봉 추세 문구는 발송하지 않는다. 제목은 `[질리카 거래량 급증]`이며 거래량·직전 20봉 중앙값 배율·거래대금·확인용 현재가만 표시한다. 상승 여부로 감지하지 않으며 방향별 메시지를 따로 보내지 않는다.
- 정책 버전은 `rolling-volume-original-v3`. 실제 `config.zil_watch`와 시작 로그에서 thresholds 및 direction_alerts=false를 확인한다.

## 운영 범위

- 기존 업비트 프로세스의 독립 asyncio 작업으로 KRW-ZIL만 매분 경계 +3초에 확인한다. 일반 후보 판단과 LBank 운영은 변경하지 않는다.
- 진행봉·미래봉은 사용하지 않는다. 종료 후 180초 이내 봉만 검사하며 과거 전체 알림을 재생하지 않는다. 0 중앙값은 제외하고 희소 기준은 표시한다.
- 영속 장부의 종목/주기/봉 시작 시각 ID로 중복을 억제하며 Telegram 수락 후에만 저장한다. 응답 유실이나 응답 직후 저장 전 종료 시 중복 가능성은 남는다.
- 매분 원본 1분·5분봉을 조회하고, 새 적격 사건 때만 현재가를 추가 조회한다. 시험 메시지는 보내지 않는다.
- `ZIL_WATCH_ENABLED=false`로 전용 감시를 중지한다. 기본 종료 시각은 기존 설정인 2026-11-16 15:00 KST를 유지한다. 이미 중지된 시간당 ChatGPT 감시와 LBank 모의 알림은 재개하지 않는다.

## 검증

전용 시험 17개: 원래 1분 5배/1,000만원·5분 3배/3,000만원 경계 복구, 문턱 직하 차단, 예전 고정 기준 변수 무시, 진행·미래·오래된 봉 제외, 중앙값 0·희소 기준, 중복·재시작·전송 실패 재시도, 종료·오래된 현재가 차단, 방향 문구 제거, 기준 미달 무발송을 확인한다. Telegram은 모킹한다. 이는 동작 검증이며 수익성 검증이 아니다.

전용 시험을 포함한 전체 회귀 **668개 통과**. 배포 완료는 해당 커밋의 SUCCESS와 실제 실행 정책·감시 tick·발송 경로를 확인한 뒤 보고한다.
