# LBank BTCUSDT 알림 시스템: 변경 및 검증 기록

작성일: 2026-10-17. 목표는 일 순수익 5%이나, 달성 가능성이나 수익성을 입증한 시스템이 아니다. 본 변경은 관찰용 알림의 논리 오류를 고치고 이후 성과를 검증할 기록을 추가한다. 주문을 실행하거나 거래소 손절 주문을 변경하지 않는다.

## 구현한 변경

1. 박스권 반등, 추세 재확인, 돌파 후보를 각각 평가한다. 한 전략의 탈락이 다른 전략의 평가를 막지 않는다. 기존 비용·위험·RSI 방향·2단계 확인 조건을 유지한다. 반대 방향이 동시에 통과하면 보류한다.
2. 1차 목표 알림을 전달한 뒤 남은 물량의 **참고 감시 손절선**을 진입가로 옮기고 재시작에도 복원한다. 거래소 주문 변경은 사용자가 해야 한다. 진입가 청산에도 거래 비용은 발생한다.
3. 진입 알림은 1차 50% 익절 예상액, 2차 나머지 50% 익절 후 합계액, 두 목표 달성 기준의 분할 순손익비를 표시한다. 전량 익절액 두 개를 합산하지 않는다.
4. SQLite에 가격표본·후보별 탈락 사유·전달된 신호의 모의 성과를 기록한다. 동일 신호를 `levels`(분할 목표)와 `warning_exit`(분할 목표 + 전달된 조기경고 때 청산) 두 방식으로 비교한다.
5. 한국시간 22:50 이후 정상 가격 수집 주기에 당일 생성 신호의 모의 성과 중간집계를 기존 Telegram 채널에 하루 한 번 전송한다. 실제 계좌 순수익 보고가 아니다. 목표 5%와 기준자금 환산액을 표시하지만 목표 미달을 이유로 위험을 늘리지 않는다.

## 연구 범위와 채택 근거

| 평균 회귀·박스권 반등 | 기존 구조 조건 유지 | 횡보 여부만으로 신호 유무나 수익성을 판단하지 않는다. |
| 호가·주문 흐름 | 기존 관찰 연구 유지 | 호가 스냅샷 비율은 체결을 포함한 주문 흐름 전체와 다르다. |

전 세계 지식을 모두 수집했다는 의미가 아니다. 서로 다른 시장·시간축에서 나온 연구를 이 거래소의 초단기 수익으로 일반화하지 않는다. 다중 전략의 사후 선택은 과최적화 위험이 있어 후보별 기록을 남긴다.

## 재현 가능한 표본 검사

입력: `research/quotes-20261017.json`의 공개 가격과 관측 시각 2,927개, 약 51.48시간. 원본 서버 로그에서 가격과 시각만 추출했으며 계정 정보는 포함하지 않는다. 정확한 기간과 입력 해시는 `research/replay-20261017.json`에 있다.

```bash
python -m unittest discover -p 'test_lbank*.py'
python research/replay_lbank.py research/quotes-20261017.json research/replay-20261017.json
```

변경 전 진입 논리와 변경 후 논리는 이 구간에서 같은 7개 신호를 생성했다. 독립 평가 수정으로 수익이 개선되었다는 증거는 없다. 위 숫자는 전체 약 51시간의 합계이며 일 수익률이 아니다. 실제 계좌 손익도 아니다.

비교 기준 진입 코드: `9e0617a6fe366a17d9f802cfc7f1d698532d0f88`. 양쪽에 동일한 새 분할 청산 계산과 참고 손절 추적을 적용했다. 과거 시점에 배포되어 있던 모든 버전의 실제 운용을 재현한 결과는 아니다. 기준자금 10,000 USDT에 정규화하고 복리·실제 잔고·동시 포지션 증거금 제약은 계산하지 않았다.

비용 가정: 진입·청산 각각 taker 0.06%, 모든 청산에 불리한 슬리피지 0.02%, 펀딩 비용 예비분 0.01%. LBank 공식 안내의 기본 수수료를 참고한 모형이며 실제 계정 수수료·펀딩이나 체결 가격을 조회한 것이 아니다. 진입은 신호 가격으로 가정해 진입 슬리피지는 포함하지 않는다. 따라서 보수적인 가정 일부가 있어도 실전 성과의 하한으로 해석할 수 없다.

검증 시점 172개 테스트 통과. 분할 비용, 롱·숏 진입가 손절, 중복 기록, 재시작 복구, 자료 공백, 순서가 뒤바뀐 관측, 보고 중복 방지와 전략 독립 평가 등을 확인했다. 테스트 통과는 수익성 증명이 아니다.

## 운영 및 데이터 한계

- 데이터는 약 1분 간격 ticker 가격 표본이다. 실제 OHLCV 봉·거래량·체결 데이터가 아니다. 표본 사이의 고저점과 목표/손절 도달 순서를 모를 수 있다.
- 관측 간격이 150초를 넘는 미완료 모의 거래는 `censored_gap`으로 분리하며 수익으로 계산하지 않는다. 정상 간격 내부의 미관측 움직임까지 탐지할 수는 없다.
- 목표 도달 체결은 가상이다. 손절은 관측된 불리한 가격으로 계산한다. 2시간을 넘은 모의 거래는 관측 가격으로 종료한다. 이 모의 시간 종료는 자동 주문이나 별도 청산 알림을 뜻하지 않는다.
- 22:50 보고는 당일 생성 신호의 당시 완료분만 포함한다. 이전 날짜 신호·미완료·자료 공백은 합계에서 제외한다. 일 전체 계좌 결산으로 사용하면 안 된다. 전송 결과가 불명확하면 중복 방지를 위해 같은 보고를 자동 재전송하지 않는다.
- 기록 장애가 확인되면 신규 진입 검토 알림을 잠시 멈추고 기존 위험 알림은 계속 처리한다. 전달 후 기록 실패는 프로세스 안에서 재시도한다. Telegram 전달과 DB 기록 사이의 프로세스 종료를 원자적으로 처리하지 못하므로 그 구간의 완전한 기록을 보장하지 않는다.
- 가격 30일, 후보 판정 7일, 완료 성과 및 보고 90일을 보존한다. 미완료 성과는 보존한다. 실제 잔고·실현손익과 연동되어 있지 않다.
- 서비스가 중지되거나 시세 수집·메시지 전달에 실패하면 알림이 늦거나 누락될 수 있다. 알림 부재만으로 횡보라고 판단할 수 없다.

## 수익성 검증을 위해 남은 일

현재 변경은 수익성이 입증된 신규 전략의 승격이 아니다. 네이티브 봉·체결 및 실제 비용 자료 확보, 사전에 고정한 후보의 별도 기간 검증, 거래당 기대손익·최대낙폭·연속 손실·비용 악화 민감도 검사가 필요하다. 단순 승률이나 짧은 기간의 순이익만으로 판단하지 않는다. 이러한 향후 연구 전부가 자동 실행되도록 구현된 것은 아니다.
