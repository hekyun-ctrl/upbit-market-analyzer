# 업비트 1분 초기 가속·재시동 — 구현 및 진단

작성: 2026-10-26 KST. 운영 기준 main `0cebe103c33f406b0871b40040f1ea2d5b4c8737`.
범위는 업비트 공개 시세·조건부 알림이다. LBank 코드·설정·중지된 모의 발송은 변경하지 않는다.

## 실제 변경

- `minute_surge.py`: 실제 WebSocket 체결을 1분별로 합산한다. 다음 분의 새 체결을 받아 이전 분이 끝난 뒤에만 평가한다. 시가·고가·저가·종가·원화 거래대금과 사전에 알려진 고점을 보존한다. 첫 부분 분, 늦은/중복/역순 입력, 재연결 부분 분과 재시작 과거 신호는 발송하지 않는다.
- 초기 가속: 완료 1분 거래대금 2천만원 이상, 이전 10개 관측 봉 중앙값의 3배 이상 또는 최근 3개 봉에서 두 차례 1.8배 이상 증가, 이전 10개 관측 고점 돌파와 강한 종가를 함께 요구한다. 20개 관측의 시간 범위도 제한한다. 이 문턱은 구현 가설이며 최적화·수익성 검증값이 아니다.
- 재시동: 이전 돌파선/구조 저점 이탈을 기억하되 새 완료 구조와 재가속은 별도 ID로 평가한다. 최초 가격 대비 고정 +5% 제한을 새 경로에 상속하지 않는다. 새 기준점 자체의 이격은 계속 제한한다. 같은 분 재평가는 중복 제거하고 시도 간 120초 간격을 둔다. 오래된 구조는 12시간 후 만료한다.
- 높은 RSI·장시간 매수세·사전 압축·1h/4h 방향을 새 경로의 일괄 필수 조건으로 만들지 않는다. 새 경로가 기존 경로를 대체하지 않는다.
- 발견은 내부 기록이다. 완료 1분봉을 REST와 대조한 뒤 현재가/돌파선 이격, 구조 밖 손절, 기존 손절폭 한도, 최소 위험보상, 3회 반복 호가 깊이·시각·스프레드, 비용 차감 손익비, BTC 급락, 8초 생존과 전송 직전 호가를 통과해야 조건부 진입 후보가 된다.
- 생존 중 실시간 구조 침범은 반등해도 같은 후보를 복구하지 않는다. 손절을 구조 안쪽으로 당겨 허용 폭에 맞추지 않는다. 알려진 과거 고가가 있으면 목표를 그 앞에 제한한다. 위 장벽이 없을 때의 5%/10% 목표는 명시적 계획 가정이며 가격 예측이 아니다.
- 기존 점수·종목 재전송·일 발송 한도와 Telegram 경로를 사용한다. 초기사전 관찰을 진입 메시지로 세지 않는다. 조기 관찰 하루 15건 한도는 이번 범위에서 바꾸지 않았고, 새 조건부 후보 심사는 그 관찰 한도와 별개다.

## 검증

- 기존 회귀와 새 경로 17개를 포함해 **651개 시험 통과**.

- 운영 코드 변화가 있어 이번 업비트 회귀를 수행했다. 이전 LBank 455/467개 시험을 반복하지 않았다.
