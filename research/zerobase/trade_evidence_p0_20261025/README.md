# P0 완료 — 공통 사건·단계별 장부·거래별 비교

기준 설계: `docs/zerobase/TRADE_EVIDENCE_ALERT_DESIGN_20261025.md`.
운영 `b4c7d94` capture와 미병합 PR #21 `ce33a017` location의 **기존 보존 결과를 계측하여 재현**했다. 새 전략·목표·확인 조건을 도입하거나 운영·발송·주문을 변경하지 않았다. P1~P5는 이 결과로 완료 처리하지 않는다.

## 바로 읽을 파일

- `TRADE_CARDS.md`: 0/15초 시나리오 전체 7개 거래 카드. 좋은 사례만 골라내지 않았다.
- `trades.csv`: 공통/제외/추가/매칭 불가, 정책별 진입·손절·목표·결과·0과 null 구분.
- `opportunities.csv`: 같은 앵커 사건의 최초 보존 관측 후보 시각 비교. 실제 최초 수신 시각이 아니다.
- `gate_decisions.csv`: 후보·확인·발송 자격 단계의 실제 실행 검사와 첫 차단/세부 원인. 실행하지 않은 검사는 `not_evaluated`다.
- `summary.json`, `manifest.json`: 입력/출력·평가 코드 해시, 분모·단계별 고유 사건 수, 정책 출력 재현 여부.

## A. 어디서 탈락했는가

관측 횟수와 고유 구조 사건을 분리했다. 원래 67→77개는 봉·전략·방향 후보 계열이고, 아래 52→61개는 불변 원문 앵커에 묶인 고유 사건이다. 서로 다른 분모를 개선률로 섞지 않는다.

15초 가정은 유효 관측 571개, 자료 미준비 228개, 가정 지연으로 제외 269개다. capture/location의 고유 사건은 40/46, 후보 심사 통과 6/2, 확인·모형 발송 자격은 2/1이다.

목표가 관측 범위 밖, 완료 5분봉 장벽과 충돌, 박스 장벽과 충돌, EMA 이격, 새 위치 한도 등이 구분됐다. `summary.json`은 단계별 첫 차단의 평가 횟수와 고유 사건 수를 따로 기록한다. 방향 예외로 통과한 검사는 `override_used`를 표시한다. 로그가 없는 계획 하위 검사를 임의로 통과/실패 판정하지 않는다. 이 계측은 E1~E5 단독 변경의 인과 비교가 아니다.

## B. 같은 기회를 실제로 더 일찍 포착했는가

- 0초 가정에서 공통 원문 앵커 후보 사건은 52개다. 최초 보존 관측 시각이 51개는 같고 1개는 기존이 빨랐다. 신규가 빨랐다는 기록은 없었다.
- 15초 가정은 공통 40개 중 39개 동시, 1개 기존이 빨랐다.
- 두 정책 모두 최종 모의 알람을 만든 **공통 사건은 0개**다. 최종 확인/발송의 개선 시차·진입가 차이는 계산할 수 없으며 CSV에 비워 뒀다.
- 후보 시각은 사용한 보존 관측 주기에서의 최초 탐지다. 실제 근거 첫 수신 시각이 없고 과거 미관측 틱도 없으므로 0이라는 중앙값을 실제 무지연 또는 실제 수신 기준 성능으로 해석하지 않는다. 운영 스케줄러를 완전히 재생한 결과도 아니다.

## 다음 구현 범위 결정

기존 숏 2건은 진행 방향의 알려진 지지가 T1보다 훨씬 가까웠으며 `single_pivots_under_aligned_15m_5m` 예외가 남아 있었다. 다른 기존 1건과 신규 1건은 장벽 미발견 상태인데도 비용 후 요구 RR에서 수치 목표를 만들었다. 이는 목표가 실제 구조에 근거한 예측이라기보다 **필요 수익 가격**이었다는 증거다.

따라서 다음은 P1의 구조 목표→허용 진입가 역산을 독립 구현할 근거가 있다. 이는 이 자료로 수익성을 검증했다는 뜻이 아니다. 기존 후보 조건을 계속 바꾸거나 장벽 차단만 추가해 횟수를 줄인 뒤 정확도 개선으로 보고하지 않는다. P2 단독 실험·새 연속 검증 구간과 실제 수신 근거는 이후 별도다.

## 검증·재현·한계

P0 전용 **15개 시험 통과**: 사건 ID/재시작/반복 입력, 늦은 확인 봉 수신·미래 입력 거절, 원문 시각 정밀도·불명 수신 시각 보존, 검사 미실행 표기, 계획+비활성 발송 의도의 트랜잭션, 불명 ACK, 근거 없는 매칭 금지, 미진입 0/미확정 null, 봉내 TP/SL 순서. 기존 467개는 생산 전략 변경이 없어 반복하지 않았다.

입력 해시 및 네 가지 capture/location×0/15초의 창별 관측·후보·거래별 출력과 집계가 기존 저장 결과와 완전히 같음을 확인했다. 단계별 계측 때문에 전략 출력이 바뀌지 않았다. 실제 발송 의도·Telegram 수락·주문은 0건이다. 1h/4h 입력은 신규 차단으로 연결하지 않았다.

재현:

```bash
python -m unittest test_lbank_signal_evidence -q
python research/compare_signal_decisions.py
python research/render_signal_evidence_report.py
```

전체 SQLite 장부·원문 입력 집합은 재현 명령으로 생성되는 중간 파일이며 저장소에 중복 보관하지 않는다. 고정 원본·코드·결과 표·입출력 해시는 저장소에 보존한다. `ingest_seq`는 **이 오프라인 가져오기의 순서**이지 실제 과거 수신 순서를 복원한 값이 아니다. actual known_at/수신·발송 시각은 null, 명목 마감+0/15초는 별도 가정이다.

자료는 기존 신호 주변의 개발 구간이다. 실제 체결·개인 비용·펀딩과 전체 시장 기회는 미검증이다. 5/15/30/60분 결과는 해당 시각까지 보유했다고 가정한 가격 평가이며 기존 청산 이후의 실현 손익이 아니다. MFE/MAE·평가손익 최대낙폭·부분 봉 미관측 경로를 새로 확정하지 않았다. P1~P5, 정식 성능 승격, 운영 장부 마이그레이션과 운영 장애 격리 연결은 미완료다.
