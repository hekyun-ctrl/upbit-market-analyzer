# 비교 전 고정한 후보 수정안

운영 기준은 4217f204. 다음 세 모드를 같은 자료와 비용으로 비교한다. 비교 결과를 본 뒤 숫자를 재조정하지 않는다.

- legacy: 기존 동작.
- structure_cost: 돌파·눌림의 손절 하한만 해당 진입 구조와 같은 1분봉 ATR의 1.5배로 계산. 최소 0.05%, 기존 5분봉 하한 이하. 실제 손절은 기존 구조의 고저점 밖에 두며 최대 0.60%, 시드 위험 한도, 증거금 한도, 비용 후 손익비 1.5와 장벽 검사는 유지한다. 박스 반등은 변경하지 않는다.
- capture: structure_cost에 추가. 눌림 최소 폭은 5분봉 ATR 1배를 쓰되 0.055~0.15% 범위. 돌파는 기존 경로를 유지하면서 실제 직전 15분 고저점 돌파, 완료 1분봉 몸통이 1분봉 ATR 및 0.055% 이상, 5·15분 가격 진전, 1분 EMA20/50 방향과 MACD가 일치하는 경로를 추가한다. 탐지와 최종 확인에서 같은 돌파 함수를 사용한다.

기존 1시간·4시간 참고 정보, RSI 방향, 45분 알림 간격, 90분 반대 방향 간격, 일 8건 상한과 비용을 변경하지 않는다. 새 모드의 운영 기본값은 legacy다.

자료: 사전 진단 압축 아카이브 5개를 해시 확인하여 복원. 서로 다른 실제 신호 3개 주변의 1분봉 1,123개/5분봉 581개(공백 표시 포함)와 해당 구간 실제 가격 로그 1,068개. 중복 봉 충돌 0. 이는 신호가 있었던 구간을 사후 보존한 편향된 표본이며 전체 시장 검증이 아니다. 첫 두 구간은 개발 비교, 마지막 10월 22일 구간은 분리 보고한다.

비교 항목: 자료 준비가 된 동일 관측에서 초기 후보, 최종 확인, 손절/목표 이동폭, 비용 후 손익비·시드 위험·증거금 불변 조건. 후보 수는 반복 평가와 구분한다. 정확한 과거 봉 도착 시각이 없는 자료는 명시적 도착 지연 가정(0초/15초)으로 각각 비교한다. 실제 가격 로그 시각은 관측 대용이며 단말 발송 시각이 아니다.

손익 비교는 동일 진입 자료와 회수한 이후 5분봉을 사용하는 별도 고정 청산 모형으로 수행한다. 1차 목표 절반·2차 목표 나머지, 기존 비용·손절 슬리피지·펀딩 가정, 6시간 제한. 실제 부분 체결·추적 알림의 완전 재현 또는 실현 수익이라고 표시하지 않는다. 시작 봉의 진입 전/후 경로, 같은 봉 양방향 접촉, 누락 구간은 미해결 또는 범위로 표시한다. 승률·낙폭은 해결된 표본만 골라 전체 성능으로 주장하지 않는다.

이 제한된 자료만으로 새 모드를 운영에 활성화하지 않는다. 충분한 기간·체결/펀딩·독립 원본 검증이 별도로 필요하다. 모의 알람을 발송하지 않는다.
