## 구현한 대안

별도 location 모드에서 다음을 묶어 검증했다. 기존 capture/legacy 경로와 모의 알림·ZB 발송 설정은 그대로다.

- 직전 10개 완료 1분봉 고저점의 실제 돌파 뒤 첫 재시험·재개를 1~3봉 안에 탐지한다. 누적 5·15분 움직임 하한을 기다리는 대신 닫힌 구조를 증거로 사용하고, 기존 5분 RSI·15분 문맥 및 돈/비용 검사는 유지한다.
- 완료 재시험 고저점을 현재 실제 공개 관측가가 넘으면 다음 1분봉 마감을 기다리지 않고 평가한다. 현재가를 완료봉으로 붙이거나 과거 15초 가격을 보간하지 않는다. 기존 위험 관측 주기에서 새 경로를 평가하고 최소 30초 확인은 유지한다.
- 돌파 수준에서 1.5 ATR1, 눌림 앵커에서 2 ATR1를 넘는 추격을 거절한다. 관찰가에서 max(0.1 USDT, 0.1 ATR1) 실제 방향 진전이 있어야 확인한다. 첫 번째 사후 완료 1분봉의 손절선 침범도 회복으로 지우지 않는다.
- 완료 5분봉의 첫 알려진 장벽이 비용 후 목표 앞에 있으면 단일 피벗도 상위 방향으로 예외 통과시키지 않는다. 위험·증거금·손절 최대폭·손익비·알람 간격·일 상한은 완화하지 않는다. 1시간·4시간은 참고 정보다.
