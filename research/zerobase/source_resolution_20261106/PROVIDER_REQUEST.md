# BTCUSDT 선물 1분봉·5분봉 데이터 관련 문의

안녕하세요.

BTCUSDT 선물 5분봉을 기준으로 분석용 알림 시스템을 준비하고 있습니다. 거래소 차트와 같은 데이터로 확인하고 싶은데, 공개 API 안내만으로는 확실하지 않은 부분이 있어 문의드립니다.

제가 확인하려는 것은 BTCUSDT USDT 결제 무기한 선물(SwapU)의 체결가격 기준 봉입니다. 아래 내용에 대해 기술 담당자분의 안내를 부탁드립니다.

**1. 과거 1분봉과 5분봉을 받을 수 있는 공식 경로가 궁금합니다.**

웹 차트에서 사용하는 것으로 확인된 경로는 다음과 같습니다.

- REST: `GET /cfd/query/v1.0/KLinelst`
- 웹소켓: `wss://uuws.rerrkvifj.com/ws/v3`의 KLine 채널(topic 2)

REST에서는 `10006 / not open path`라는 응답이 확인됐습니다. 로그인 없이 공개 선물 봉을 조회할 수 있는 정식 API 주소와 요청 예시가 있을까요? 지원하는 봉 주기, 과거 조회 범위, 호출 제한도 함께 알려주시면 감사하겠습니다.

**2. 봉이 최종 마감됐는지는 어떤 값으로 확인해야 하나요?**

1분봉과 5분봉이 더 이상 진행 중이 아니라는 것을 확인할 수 있는 필드나 별도의 메시지가 있는지 알고 싶습니다.

현재 확인된 필드에는 `j=timeZone`, `k=updateTime`이 있고, 마감 전에도 `tradeTime=true`가 나타납니다. 어떤 값을 기준으로 마감을 판단해야 하는지, 마감 후에도 봉이 수정될 수 있는지 안내 부탁드립니다. 연결이 끊겼다가 다시 이어졌을 때 누락된 봉과 수정된 봉을 확인하는 방법도 궁금합니다.

**3. 거래소에서 제공하는 마감된 5분봉을 직접 받고 싶습니다.**

1분봉 다섯 개를 직접 합성하는 대신, 거래소가 제공하는 마감된 5분봉과 같은 시간대의 1분봉을 함께 받아 비교하고 싶습니다.

현재 받은 자료는 처음에 진행 중인 5분봉 스냅샷이 오고, 이후에는 1분봉 갱신이 이어지는 형태였습니다. 과거에 마감된 5분봉을 받는 방법과, 거래소에서 각 주기의 봉을 집계하고 발행하는 기준을 알려주세요.

**4. 거래량과 거래대금의 정확한 단위를 확인하고 싶습니다.**

BTCUSDT/SwapU 봉에서 `h=volume`은 BTC 수량인가요, 계약 수인가요? `i=turnover`는 USDT 기준 거래대금으로 보면 될까요?

11월 6일 오전 9시 41분경(한국시간)에 확인된 BTCUSDT 종목 정보에는 `baseCurrency=BTC`, `priceCurrency=clearCurrency=USDT`, `volumeMultiple=1`로 나와 있습니다. 웹 차트에서도 거래량에 `volumeMultiple`을 적용하는 것으로 확인됐는데, 봉의 거래량을 해석할 때 이 배수를 별도로 적용해야 하는지 정확히 알고 싶습니다.

**5. 실제로 정산된 과거 펀딩비율은 어디서 조회할 수 있나요?**

현재 표시되는 값이나 다음 정산의 예상값이 아니라, 과거에 실제 정산된 펀딩비율과 정산 시각을 조회하고 싶습니다. 공개 조회 경로와 비율의 단위, 정산 주기를 안내 부탁드립니다.

관련 공식 문서나 실제 응답 예시가 있다면 함께 보내주시면 큰 도움이 되겠습니다. 필요하시면 현재 확인된 응답 예시도 전달드리겠습니다.
